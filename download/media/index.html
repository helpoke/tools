媒体下载：网页图片/视频提取与批量下载工具

一、媒体下载的应用场景

  • 设计师需要从参考网站批量下载高清图片——手动右键保存效率极低。开发者需要提取网页中所有图标资源——逐张查找费时费力。用户需要下载网页中嵌入的视频——但视频地址被隐藏在页面源码中。
  • 本工具提供三种下载模式：直接 URL 批量下载（粘贴多个文件链接，一键下载）、网页图片提取（输入网页地址，自动提取页面中所有图片）、网页视频提取（输入网页地址，自动检测页面中的视频源地址）。
  • 支持并发下载（同时下载多个文件）、文件类型筛选（只下载图片/视频/全部）、最小文件大小过滤（跳过小图标）、ZIP 打包下载（所有文件打包为一个 ZIP）。所有下载通过浏览器原生 fetch API 完成。

二、支持的媒体格式

  • 图片格式：JPG、PNG、GIF、WebP、SVG、ICO、BMP——覆盖所有常见图片格式。提取时自动检测图片 MIME 类型。
  • 视频格式：MP4、WebM、OGG、M3U8（HLS 流媒体）——支持直接链接和流媒体地址。注意：DRM 保护的视频无法下载。
  • 音频格式：MP3、AAC、OGG、WAV——网页中嵌入的音频文件也可以提取。

三、核心功能

  • URL 批量下载：粘贴多个文件链接（每行一个）——支持自动修正不规范的 URL 格式。
  • 网页提取：输入网页地址——自动提取页面中的图片/视频缩略图和源地址。
  • ZIP 打包：多个文件自动打包为 ZIP 下载——不需要逐个保存。
  • 浏览器下载：使用浏览器原生 fetch API——下载行为与正常浏览一致。

媒体下载操作指南

直接 URL 下载

  • 输入链接：每行输入一个文件下载链接——支持 HTTP/HTTPS 协议。
  • 自动修正：工具自动格式化不规范的 URL——移除前导符号、补充缺失的协议头。
  • 批量支持：支持数百个链接同时下载——并发数可配置。

网页图片提取

  • 输入网页地址：输入完整的网页 URL——工具自动请求页面并提取图片。
  • 自动提取：解析页面 HTML 提取所有 img 标签的 src 属性——包括懒加载图片。
  • 选择图片：提取结果显示缩略图——勾选需要下载的图片。
  • 添加到队列：选中的图片添加到下载队列——可以多次提取不同页面后统一下载。

网页视频提取

  • 输入网页地址：输入包含视频的网页 URL。
  • 自动检测：解析页面中的 video/source 标签和 JavaScript 中的视频源地址。
  • 选择视频：检测到的视频显示列表——勾选需要下载的视频。
  • 添加到队列：选中的视频添加到下载队列。

下载设置

  • 并发数：设置同时下载的文件数——建议 3-5 个，过多可能触发网站反爬。
  • 文件类型：筛选下载的文件类型——全部、仅图片、仅视频。
  • 最小大小：设置最小文件大小——过滤掉小图标和缩略图。

开始下载

  • 点击下载：点击"开始下载"按钮——队列中的文件按顺序下载。
  • 查看进度：进度面板显示每个文件的下载状态——等待中、下载中、完成、失败。
  • 清除队列：点击"清除"按钮清空下载队列——重新开始。

注意事项

限制说明

  • CORS 限制：跨域请求受浏览器安全策略限制——某些网站的资源可能无法提取。工具会提示 CORS 错误。
  • 防盗链：某些网站设置了防盗链——直接下载链接可能返回 403 错误。
  • 登录资源：需要登录才能访问的资源无法提取——工具不携带登录 Cookie。
  • 网络依赖：下载需要网络连接——提取结果取决于目标网站的响应。

处理建议

  • 资源不可用：如果提取失败，尝试直接在浏览器中打开资源链接——确认资源是否可访问。
  • 手动下载：自动提取失败时，可以在浏览器开发者工具的 Network 面板中手动查找资源链接。

数据安全

  • 浏览器下载：所有下载通过浏览器原生 API 完成——不经过第三方服务器中转。
  • 版权提醒：下载的媒体文件可能受版权保护——仅用于个人学习和合理使用。

处理说明

  • 提取范围：只提取当前页面的静态资源——不递归提取子页面或 iframe 中的资源。
  • 动态加载：JavaScript 动态加载的图片/视频可能无法提取——工具只解析初始 HTML。

常见问题

  • Q: 提取不到图片？A: 可能是 CORS 限制或图片通过 JavaScript 动态加载——尝试在浏览器开发者工具中手动查找。
  • Q: 下载失败 403？A: 目标网站设置了防盗链——尝试直接在浏览器中打开链接下载。
  • Q: 视频无法播放？A: M3U8/HLS 流媒体地址不能直接下载——需要使用专用 HLS 下载工具。
  • Q: 能下载需要登录的资源吗？A: 不能——工具不携带登录凭证。需要登录的资源请手动下载。
