Unicode 编码

Unicode 编码转换：Unicode、UTF-8、UTF-16 的互转工具

一、Unicode 编码的困惑

  • "你好"这两个汉字在计算机中如何表示？Unicode 给出的答案是 U+4F60 U+597D——两个码点。但这两个码点在文件中如何存储？UTF-8 用 3 字节表示每个汉字（E4 BD A0 E5 A5 BD），UTF-16 用 2 字节（4F60 597D），UTF-32 用 4 字节。同一段文字，三种编码占用的空间完全不同。
  • 本工具支持 Unicode 编码的各种转换——将中文文本转为 Unicode 转义序列（\u4F60\u597D），也可将转义序列还原为原始文字。支持 \uXXXX 和 \u{XXXXX} 两种格式，支持只编码中文字符（保留 ASCII 不变）。
  • 在 JavaScript、Java、JSON 等语言中，Unicode 转义序列有特殊的语法规则——本工具生成的格式与这些语言完全兼容，可以直接粘贴到代码中使用。

二、Unicode 编码格式

  • Unicode 码点：每个字符对应一个唯一的码点（code point），用 U+ 前缀表示——如 U+4E2D（中）、U+6587（文）。基本平面（BMP）范围 U+0000 到 U+FFFF，扩展平面范围 U+10000 到 U+10FFFF。
  • UTF-8 编码：可变长度编码——ASCII 字符 1 字节，拉丁字符 2 字节，中文/日文 3 字节，emoji 4 字节。互联网上最流行的编码格式——兼容 ASCII，无字节序问题。
  • UTF-16 编码：BMP 字符 2 字节，扩展字符 4 字节（用代理对表示）。Java 和 JavaScript 内部使用 UTF-16 表示字符串——这就是为什么 JavaScript 的 .length 属性对 emoji 返回 2。

三、核心功能

  • 编码转换：中文文本 → Unicode 转义序列（\u4F60\u597D）。支持只编码中文字符——英文和数字保持原样不变。
  • 解码还原：Unicode 转义序列 → 原始文本。支持 \uXXXX 和 \u{XXXXX} 两种格式混合解码。
  • 批量处理：支持大段文本的一次性编解码——适合处理配置文件、国际化资源文件。
  • 纯前端处理：所有转换在浏览器中完成——文本不上传到服务器。

五、Unicode 格式详解

  • \uXXXX 格式：4 位十六进制——覆盖 BMP 平面（U+0000 到 U+FFFF）。JavaScript、Java、JSON 使用此格式。
  • \u{XXXXX} 格式：可变长度——覆盖全部 Unicode 范围（到 U+10FFFF）。ES6+ JavaScript 和 Python 3.3+ 支持此格式。
  • 十六进制表示：Unicode 码点通常用十六进制表示——如 U+4E2D = 中，U+1F600 = 笑脸 emoji。

注意事项

格式注意

  • 代理对：超过 U+FFFF 的字符（如 emoji）在 UTF-16 中用两个 16 位单元表示——称为代理对（surrogate pair）。
  • BOM 标记：UTF-16 文件可能以 BOM（Byte Order Mark）开头——标识字节序。本工具处理的是文本层面的 Unicode，不涉及 BOM。
  • 编码兼容：UTF-8 完全兼容 ASCII——纯 ASCII 文本同时也是合法的 UTF-8 文本。

字符范围

  • 基本多文种平面（BMP）：U+0000 到 U+FFFF——包含几乎所有常用文字。\uXXXX 格式可覆盖此范围。
  • 扩展平面：U+10000 到 U+10FFFF——包含罕见汉字、历史文字、emoji 等。需要 \u{XXXXX} 格式。
  • 私有区域：U+E000 到 U+F8FF 为私有使用区域——不同字体可能显示不同字符。

数据安全

  • 纯前端处理：所有转换在浏览器中完成——文本不上传到服务器。
  • 无网络依赖：页面加载完成后离线也能正常使用。
  • 编码非加密：Unicode 编码转换不提供安全性——任何人都能解码。

常见问题

  • Q: \u 和 \U 有什么区别？A: \u 后跟 4 位十六进制（JavaScript/Java），\U 后跟 8 位（Python/C++）。本工具支持 \u 格式。
  • Q: emoji 编码后变成两个 \u？A: emoji 在 BMP 之外——UTF-16 用代理对表示，所以一个 emoji 变成两个 \uXXXX。这是正常的。
  • Q: 编码结果在 JSON 中能用吗？A: 可以。JSON 规范支持 \uXXXX 转义——编码结果可直接放入 JSON 字符串值中。
  • Q: 只编码中文是什么意思？A: 勾选后，ASCII 字符（英文、数字、标点）保持原样——只有非 ASCII 字符被转为 \uXXXX。适合在保留可读性的同时编码特殊字符。
