SHA 哈希家族：从 SHA-1 到 SHA-512 的安全哈希计算

一、SHA 算法家族概览

  • SHA（Secure Hash Algorithm）是美国国家安全局（NSA）设计的一系列哈希函数。SHA-1 输出 160 位哈希（已不安全），SHA-2 家族包含 SHA-256（256 位）和 SHA-512（512 位）——目前仍被认为是安全的。SHA-3 是 2015 年发布的最新标准，基于完全不同的 Keccak 算法。
  • 本工具支持 SHA-1、SHA-256、SHA-384、SHA-512 四种算法——覆盖从旧系统兼容到最高安全需求的全部场景。支持文本和文件两种输入模式，支持大写/小写输出，支持批量计算。
  • 还提供哈希校验功能——输入文本和预期哈希值，工具自动计算并对比。如果哈希不匹配，显示实际计算结果——方便排查编码格式差异。

二、SHA 算法对比

  • SHA-1（160 位）：输出 40 位十六进制。2005 年被证明存在碰撞漏洞——2017 年 Google 实现了实际碰撞攻击。不应用于安全场景，仅用于旧系统兼容（如 Git 的对象哈希）。
  • SHA-256（256 位）：输出 64 位十六进制。目前最广泛使用的安全哈希——比特币挖矿、SSL 证书、密码存储（配合 bcrypt）都使用 SHA-256。计算速度和安全性的最佳平衡。
  • SHA-512（512 位）：输出 128 位十六进制。比 SHA-256 更安全，但在 32 位处理器上速度较慢——64 位处理器上 SHA-512 可能比 SHA-256 更快（因为内部运算效率更高）。

三、核心功能

  • 多算法支持：SHA-1、SHA-256、SHA-384、SHA-512 一键切换——不同算法的输出同时显示，方便对比。
  • 文本和文件：文本模式直接输入计算；文件模式上传文件计算——大文件使用流式处理避免内存溢出。
  • 哈希校验：输入预期哈希值，工具自动对比——匹配显示绿色，不匹配显示红色和实际值。
  • 纯前端计算：基于 Web Crypto API 实现——利用浏览器原生加密能力，性能接近系统级工具。

SHA 操作指南

加密模式

  • 选择算法：从下拉菜单选择 SHA-1/256/384/512——不同场景选择不同算法。
  • 大小写：选择大写或小写输出——哈希值不区分大小写，但某些系统要求特定格式。
  • 批量模式：勾选批量模式后，每行文本独立计算哈希——适合批量校验。
  • 输入文本：输入需要计算哈希的文本。
  • 点击计算：点击"加密"按钮，哈希值立即显示。
  • 加载文件：点击"加载文件"按钮上传文件——文件内容自动计算哈希。
  • 复制结果：点击"复制"按钮将哈希值复制到剪贴板。

校验模式

  • 输入原文：输入需要校验的原始文本。
  • 输入哈希：输入预期的哈希值——工具自动忽略大小写对比。
  • 查看结果：匹配显示"验证通过"，不匹配显示"不匹配"和实际哈希值。
  • 算法一致：校验时使用与加密相同的算法——SHA-256 的哈希必须与 SHA-256 对比。

五、SHA 技术背景

  • SHA-256 应用：比特币使用双重 SHA-256（SHA-256d）作为工作量证明。TLS/SSL 证书使用 SHA-256 签名。Git 使用 SHA-1（正在迁移到 SHA-256）。
  • SHA-512 优势：在 64 位处理器上，SHA-512 的吞吐量可能高于 SHA-256——因为内部使用 64 位运算，一次处理更多数据。
  • 单向性：哈希函数是单向的——从哈希值无法反推原始输入。这是密码存储的安全基础。
  • 固定输出：无论输入多长，输出长度固定——SHA-256 始终输出 64 个十六进制字符。

注意事项

安全建议

  • 密码存储：不要直接用 SHA-256 存储密码——SHA-256 计算太快，容易被暴力破解。请使用 bcrypt、scrypt 或 Argon2（带盐值和迭代次数）。
  • 数字签名：SHA-256 和 SHA-512 适合数字签名——SHA-1 已不安全，不应用于签名。
  • 文件校验：SHA-256 适合文件完整性校验——比 MD5 更安全，碰撞概率极低（2⁻¹²⁸）。

算法选择

  • SHA-1：仅用于旧系统兼容——如 Git 对象哈希、旧版 TLS。新系统不应使用。
  • SHA-256：通用首选——安全性足够，性能良好，兼容性最广。
  • SHA-512：最高安全需求——或 64 位平台上需要更高吞吐量时使用。

格式说明

  • 十六进制：SHA 输出是二进制数据——通常用十六进制字符串表示。SHA-256 = 32 字节 = 64 个十六进制字符。
  • Base64：某些场景用 Base64 表示哈希——更短但不如十六进制直观。
  • 大小写：十六进制哈希不区分大小写——但某些系统（如 Linux sha256sum）输出小写。

常见问题

  • Q: SHA-256 和 SHA-2 有什么区别？A: SHA-2 是算法家族（包含 SHA-256、SHA-384、SHA-512），SHA-256 是其中最常用的成员。
  • Q: SHA-256 会被破解吗？A: 目前没有已知的碰撞攻击。以当前计算能力，暴力破解 SHA-256 需要 2¹²⁸ 次运算——宇宙寿命内不可能完成。
  • Q: 同一文本的 SHA-256 每次一样吗？A: 是的——哈希函数是确定性的，相同输入始终产生相同输出。
  • Q: 不同算法能对比吗？A: 不能——SHA-256 和 SHA-512 的输出长度不同，算法不同，哈希值没有可比性。
