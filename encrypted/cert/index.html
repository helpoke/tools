X.509 证书：互联网信任基础设施

为什么需要证书解析

  • X.509 证书用于 HTTPS、代码签名、邮件加密等场景。手动阅读 PEM 文件不直观，本工具将证书中的关键字段提取为可读信息。
  • 通过解析证书，您可以快速确认域名归属、颁发机构、有效期和公钥算法，排查 SSL 配置问题。

核心功能

  • 字段提取：主题、颁发者、有效期、序列号、签名算法、公钥信息。
  • 扩展解析：Subject Alternative Name、Key Usage 等常用扩展。
  • 指纹计算：自动计算 SHA-1 和 SHA-256 指纹。
  • 本地解析：证书数据不上传服务器。

使用指南

使用步骤

  • 输入证书：复制 PEM 格式证书文本到输入框，包括 -----BEGIN CERTIFICATE----- 和 -----END CERTIFICATE-----。
  • 点击解析：工具将自动解码 ASN.1 结构并展示关键信息。
  • 验证信息：核对域名、颁发者和有效期是否与预期一致。

安全建议

  • 隐私保护：证书本身通常包含公开信息，但私钥不应包含在证书中。切勿粘贴包含私钥的 PEM 文件。
  • 验证链：单张证书解析不能替代完整的证书链验证，生产环境应使用系统或浏览器内置验证。

技术优势与典型场景

典型应用场景

  • HTTPS 证书检查：快速查看网站 SSL/TLS 证书的颁发者、有效期、域名覆盖范围和签名算法，排查证书配置问题。
  • 代码签名验证：解析软件发布者的代码签名证书，确认签名者身份和证书链可信度。
  • 邮件加密与签名：查看 S/MIME 证书中的公钥和身份信息，确保加密邮件和数字签名的合法性。
  • 物联网与 API 安全：在设备接入和 API 通信中，验证服务端证书是否正确配置。

技术优势

  • 纯本地解析：使用 JavaScript 在浏览器本地解码 ASN.1 结构，证书数据不会上传到服务器。
  • 字段全面：自动提取主题、颁发者、有效期、序列号、签名算法、公钥信息、扩展等关键字段。
  • 指纹计算：自动计算 SHA-1 和 SHA-256 指纹，方便与官方公布值比对。
  • 隐私安全：证书本身通常包含公开信息，解析过程不会影响安全性。

证书安全判断要点

一张可信的证书应满足：由受信任 CA 签发、有效期未过期、签名算法为 SHA-256 或更高、SAN 包含目标域名。若使用自签名证书，需手动添加到受信任根证书存储中。

常见问题

  • Q: 证书解析能验证证书链吗？A: 本工具只解析单张证书的内容，不验证证书链的信任关系。验证证书链需要依赖操作系统或浏览器的内置信任存储，或使用 openssl verify 等命令行工具。
  • Q: 自签名证书为什么不被信任？A: 自签名证书没有根 CA 的签名背书——浏览器和操作系统无法确认其真实性。工具会显示颁发者和主题相同。需要将自签名证书手动导入信任存储。
  • Q: 证书指纹有什么用？A: 证书指纹是证书内容的哈希值，用于快速验证证书身份。比如下载了一个证书文件，可以对比指纹确认它确实是你要的那个证书，没有被中间人替换。
  • Q: 签名算法 SHA-1 和 SHA-256 有什么区别？A: SHA-1 已被证明存在碰撞漏洞，主流浏览器已不再信任 SHA-1 签名的证书。SHA-256 是目前推荐的标准，新证书应一律使用 SHA-256 或更高算法。
