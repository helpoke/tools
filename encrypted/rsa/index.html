工具介绍

一、解决的问题

  • 生成RSA公钥和私钥密钥对，用于加密通信和数字签名。
  • 简化密钥生成流程，无需安装OpenSSL等工具。
  • 无需安装专业软件，随时随地在线使用。

二、支持的格式

  • PEM格式：Base64编码的文本格式，广泛用于Web和SSL/TLS场景，最常用的格式。
  • DER格式：二进制格式的Base64编码，常用于Java等编程语言。
  • SSH格式：OpenSSH公钥格式，用于SSH登录和Git配置。
  • JWK格式：JSON Web Key格式，用于JWT和Web加密。

三、核心功能

  • Web Crypto API：使用浏览器原生加密API，安全可靠。
  • 多种密钥长度：支持1024/2048/3072/4096位密钥。
  • 多种导出格式：支持PEM、DER、SSH、JWK四种格式导出。
  • 数据安全：所有密钥仅在本地生成，不会上传到服务器。

使用说明

一、选择密钥参数

  • 密钥长度：选择RSA密钥的位长度。推荐2048位（安全且性能好），4096位安全性最高但生成较慢。
  • 导出格式：支持PEM（最常用）、DER（二进制）、SSH（OpenSSH）、JWK（JSON）四种格式。

二、生成密钥对

  • 点击生成：点击「生成密钥对」按钮，等待密钥生成完成。密钥长度越大，生成时间越长。
  • 查看结果：生成的公钥和私钥将分别显示在对应的文本框中。
  • 复制/下载：点击「复制」按钮复制到剪贴板，或点击「下载」按钮保存为.pem文件。

三、密钥使用说明

  • 公钥：可以公开分享，用于加密数据或验证签名。
  • 私钥：必须严格保密，用于解密数据或创建数字签名。
  • 安全建议：私钥请妥善保管，不要通过网络传输或存储在不安全的位置。

注意事项

一、密钥安全

  • 所有密钥在本地浏览器中生成，数据不会上传到服务器。
  • 私钥必须严格保密，切勿泄露给他人。
  • 建议使用安全的密钥管理方案存储私钥。

二、密钥长度选择

  • 1024位：已不推荐用于生产环境，安全性较低。
  • 2048位：当前推荐标准，安全性足够大多数场景。
  • 3072/4096位：更高安全性，但生成和使用速度较慢。

三、常见问题

  • 生成很慢：密钥长度越大，生成时间越长。4096位可能需要数秒。
  • 浏览器不支持：本工具需要Web Crypto API支持，请使用现代浏览器（Chrome、Firefox、Edge、Safari）。
  • 复制失败：检查浏览器是否允许剪贴板访问权限。
