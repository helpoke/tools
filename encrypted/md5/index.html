# 原文 MD5

工具介绍

一、解决的问题

  • 计算文件或文本的MD5哈希值，验证数据完整性。
  • 简化繁琐的手动操作，提高工作效率和准确性。
  • 无需安装专业软件，随时随地在线使用。

二、支持的格式

  • MD5：支持该格式的完整处理功能。

三、核心功能

  • 在线处理：所有操作均在浏览器中完成，无需下载或安装。
  • 实时预览：处理结果即时显示，方便调整和确认。
  • 一键导出：支持快速导出处理后的文件或复制结果。
  • 数据安全：所有数据仅在本地处理，不会上传到服务器。

使用说明

一、MD5生成

  • 输入文本：在文本框中输入需要计算MD5的文本内容。
  • 选择输出格式：可选择输出大小写（小写/大写）和位数（32位/16位）。
  • 点击生成：点击"生成 MD5"按钮计算MD5哈希值。
  • 复制结果：点击复制按钮将结果复制到剪贴板。

二、MD5校验

  • 输入原始文本：在"原始文本"文本框中输入原始内容。
  • 输入待校验哈希值：在"待校验的 MD5 哈希值"输入框中输入要验证的MD5值。
  • 点击校验：点击"校验 MD5"按钮验证文本与哈希值是否匹配。
  • 查看结果：校验结果会显示匹配或不匹配，并给出实际计算的MD5值。

三、批量生成

  • 输入文本：在文本框中输入多行文本，每行一个，用于批量计算MD5。
  • 选择输出格式：可选择输出大小写和位数。
  • 点击批量生成：点击"批量生成"按钮计算所有行的MD5值。
  • 复制结果：点击"复制全部结果"按钮复制所有MD5值，或点击每行的复制按钮单独复制。

四、MD5 基础

  • 哈希算法：MD5是一种单向哈希算法，将任意长度的数据转换为128位的哈希值。
  • 32位MD5：完整的MD5哈希值，由32个十六进制字符组成。
  • 16位MD5：截取32位MD5的中间16位，常用于数据库存储。
  • 特点：相同输入总是产生相同输出，不同输入产生不同输出（极高概率）。

注意事项

一、数据安全

  • 所有处理完全在本地浏览器中完成，数据不会上传到服务器。
  • MD5是不可逆的哈希算法，无法从MD5值还原原始数据。
  • 不要将MD5作为密码存储方案，建议使用更安全的哈希算法如bcrypt。

二、MD5局限性

  • MD5已被证明存在碰撞漏洞，不适合用于安全关键场景。
  • 对于密码存储，建议使用SHA-256、bcrypt、Argon2等更安全的算法。
  • MD5仍可用于文件校验、数据完整性验证等非安全场景。

三、格式规范

  • MD5校验不区分大小写，输入大写或小写的哈希值都可以正确校验。
  • 16位MD5是32位MD5的中间16位，即第9-24位。
  • 批量生成时，空行会被视为空字符串计算MD5。

四、常见问题

  • 校验不匹配：检查原始文本是否与生成MD5时的文本完全一致，包括空格和换行符。
  • 结果为空：确认输入内容不为空。
  • 复制失败：检查浏览器是否允许剪贴板访问。
