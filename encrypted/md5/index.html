# 原文 MD5

MD5 哈希计算：文件完整性校验的经典算法

一、MD5 的应用场景

  • 从网上下载了一个 2GB 的安装包——如何确认文件没有损坏或被篡改？MD5 哈希就是答案。将文件输入 MD5 算法，得到一个 32 位十六进制字符串——与官方公布的哈希值对比，完全一致说明文件完整。
  • 本工具支持三种模式：单文本 MD5 生成（支持 16 位/32 位、大小写切换）、MD5 校验（输入文本和预期哈希值，自动对比）、批量生成（一次计算多行文本的 MD5）。
  • MD5 由 Ronald Rivest 于 1991 年设计，输出 128 位（16 字节）哈希值。虽然已被证明存在碰撞漏洞（不适合密码存储和安全签名），但在文件校验、数据去重、缓存键生成等非安全场景中仍被广泛使用。

二、MD5 输出格式

  • 32 位 MD5：128 位哈希值的完整十六进制表示——如 5d41402abc4b2a76b9719d911017c592。这是最常用的格式。

三、核心功能

  • 单文本生成：输入任意文本，立即计算 MD5 哈希——支持 16 位/32 位输出和大小写切换。
  • MD5 校验：输入文本和预期哈希值，工具自动计算并对比——显示匹配或不匹配结果。
  • 批量生成：每行一个文本，一键计算所有行的 MD5 哈希——适合批量校验和数据去重。
  • 纯前端计算：所有哈希计算在浏览器中完成——文本不上传到服务器。基于 Web Crypto API 或原生 JS 实现。

MD5 操作指南

生成模式

  • 输入文本：在输入框中输入需要计算哈希的文本。
  • 选择格式：32 位（完整哈希）或 16 位（取中间 16 字符）。大写或小写输出。
  • 点击生成：点击"生成 MD5"按钮，结果立即显示。
  • 复制结果：点击"复制"按钮将哈希值复制到剪贴板。

校验模式

  • 输入原文：输入需要校验的原始文本。
  • 输入哈希：输入预期的 MD5 哈希值——工具自动忽略大小写对比。
  • 点击校验：工具计算文本的 MD5 并与预期值对比。
  • 查看结果：匹配显示绿色提示，不匹配显示红色提示和实际哈希值。

批量模式

  • 输入文本：每行输入一个需要计算哈希的文本。
  • 选择格式：32 位或 16 位，大写或小写。
  • 点击批量生成：所有行的 MD5 哈希一次性计算完成。
  • 复制全部：点击"复制全部"按钮将所有结果复制到剪贴板。

五、MD5 技术背景

  • 哈希函数：将任意长度的输入映射为固定长度的输出——MD5 输出始终为 128 位（32 位十六进制）。
  • 32 位 vs 16 位：32 位是完整哈希，16 位取中间 16 字符（第 9-24 字符）。16 位碰撞概率更高，仅用于非安全场景。
  • 十六进制表示：每 4 位二进制用 1 个十六进制字符表示——128 位 = 32 个十六进制字符。
  • 雪崩效应：输入改变一个字符，输出的每一位都有约 50% 概率改变——确保哈希值均匀分布。

注意事项

安全警告

  • 不适合密码存储：MD5 碰撞攻击已被实际演示——不要用于密码哈希。密码存储请使用 bcrypt、scrypt 或 Argon2。
  • 不适合数字签名：MD5 的碰撞抗性已被打破——攻击者可以构造两个不同文件但哈希相同。数字签名请使用 SHA-256。
  • 适合文件校验：在非对抗性场景中（如文件传输完整性检查），MD5 仍然可靠——意外损坏导致哈希匹配的概率极低。

局限性

  • 碰撞攻击：2004 年王小云教授团队首次实现 MD5 碰撞攻击——可在秒级构造碰撞对。
  • 长度扩展攻击：MD5 的 Merkle-Damgård 结构存在长度扩展漏洞——攻击者可在不知道原始输入的情况下追加数据。
  • 替代方案：安全场景请使用 SHA-256（通用）或 SHA-3（最新标准）。密码场景请使用 bcrypt 或 Argon2。

格式说明

  • 大小写：MD5 哈希的十六进制表示不区分大小写——5D41402A 和 5d41402a 是同一个哈希。
  • 16 位格式：取 32 位哈希的第 9-24 个字符——这是一种非标准的简写格式，仅用于降低显示长度。
  • 空字符串：空字符串的 MD5 是 d41d8cd98f00b204e9800998ecf8427e——不是空值。

常见问题

  • Q: MD5 能解密吗？A: MD5 是单向哈希——理论上不可逆。但常见弱密码的 MD5 已被收录到彩虹表中——可以通过查表"反查"。
  • Q: 不同工具计算的 MD5 不一样？A: 检查编码格式——UTF-8 和 GBK 编码的同一文字产生不同的 MD5。本工具使用 UTF-8 编码。
  • Q: 文件也能算 MD5 吗？A: 可以——但本工具仅支持文本输入。文件 MD5 请使用命令行工具（如 md5sum）或专用文件哈希工具。
