使用说明

一、上传图片

  • 点击上传：点击上传区域或拖拽图片到上传区域。
  • 批量上传：支持多选上传。
  • 支持格式：支持 JPG、PNG、WebP、GIF、BMP 格式。

二、添加去水印区域

  • 添加区域：点击"添加区域"按钮，在图片上绘制去水印区域。
  • 绘制区域：拖动鼠标绘制矩形区域覆盖水印。
  • 删除区域：点击"删除当前区域"按钮删除选中区域。
  • 多个区域：支持添加多个去水印区域。

三、选择去水印方式

  • 智能填充：使用周围像素智能填充水印区域，效果自然。
  • 模糊处理：对水印区域进行高斯模糊处理。
  • 马赛克覆盖：使用马赛克效果覆盖水印区域。
  • 羽化边缘：对水印区域进行边缘羽化处理。
  • 颜色覆盖：使用指定颜色覆盖水印区域。
  • 中值模糊：使用中值滤波算法去除水印。

四、调整参数

  • 模糊半径：调整模糊处理的半径（1-50）。
  • 马赛克大小：调整马赛克块的大小（2-30）。
  • 羽化强度：调整羽化边缘的强度（50%-100%）。
  • 覆盖颜色：选择颜色覆盖的颜色，可点击"自动检测"自动选择。

五、应用去水印

  • 点击应用：点击"应用去水印"按钮执行处理。
  • 查看结果：处理结果显示在结果区域。
  • 保存图片：点击"保存图片"或"下载单个图片"按钮保存结果。
  • 批量下载：点击"下载全部图片"按钮打包下载所有处理后的图片。

六、去水印方式选择建议

  • 复杂背景：使用智能填充，效果最自然。
  • 纯色背景：使用颜色覆盖或智能填充。
  • 文字水印：使用智能填充或模糊处理。
  • 需要掩盖：使用马赛克覆盖。

工具介绍

一、解决的问题

  • 去除图片中的水印和文字。
  • 简化繁琐的手动操作，提高工作效率和准确性。
  • 无需安装专业软件，随时随地在线使用。

二、支持的格式

  • JPG：支持该格式的完整处理功能。
  • PNG：支持该格式的完整处理功能。
  • WebP：支持该格式的完整处理功能。

三、核心功能

  • 在线处理：所有操作均在浏览器中完成，无需下载或安装。
  • 实时预览：处理结果即时显示，方便调整和确认。
  • 一键导出：支持快速导出处理后的文件或复制结果。
  • 数据安全：所有数据仅在本地处理，不会上传到服务器。

注意事项

一、数据安全

  • 所有处理完全在本地浏览器中完成，数据不会上传到服务器。
  • 图片文件仅在浏览器内存中处理，处理完成后自动清除。
  • 建议在处理敏感图片时使用隐私模式浏览。

二、去水印效果

  • 去水印效果取决于图片背景复杂度和水印位置。
  • 复杂背景下智能填充效果最好。
  • 纯色背景下颜色覆盖效果更精确。
  • 建议尝试不同的去水印方式找到最佳效果。

三、区域选择

  • 区域应完全覆盖水印，不要过大以免影响其他内容。
  • 可以添加多个区域处理不同位置的水印。
  • 区域数量显示在预览区域下方。

四、参数调整

  • 模糊半径过大可能导致过度模糊。
  • 马赛克大小过大可能影响周围区域。
  • 羽化强度越高，边缘越自然。
  • 自动检测颜色可能不完全准确，可手动调整。

五、性能提示

  • 大尺寸图片处理需要较长时间，请耐心等待。
  • 处理期间不要关闭浏览器或刷新页面。
  • 建议在去水印前先压缩图片以提高处理速度。
  • 批量下载会打包为ZIP文件。

六、常见问题

  • 去水印效果不佳：尝试选择不同的去水印方式。
  • 区域无法绘制：确保已添加区域并在图片上拖动。
  • 颜色检测不准确：手动选择合适的颜色。
  • 下载失败：检查浏览器下载权限设置。
