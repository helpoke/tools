工具介绍

一、解决的问题

  • 快速调整图片尺寸以适应不同平台的需求（网页、社交媒体、打印等）。
  • 批量统一产品图片尺寸，保持页面展示的一致性。
  • 无需安装专业软件，随时随地在线调整图片大小。

二、支持的格式

  • 输入格式：支持 JPG、PNG、WebP、GIF、BMP。
  • 输出格式：支持 JPG、PNG、WebP，也可保持原始格式。

三、核心功能

  • 自由缩放：支持自定义宽度和高度，灵活调整图片尺寸。
  • 宽高比锁定：保持图片比例不变，避免拉伸变形。
  • 预设尺寸：提供常见分辨率一键选择，快速切换。
  • 格式转换：缩放同时可转换为 JPG、PNG、WebP 格式。
  • 数据安全：所有数据仅在本地处理，不会上传到服务器。

使用说明

一、上传图片

  • 点击上传：点击上传区域或拖拽图片到上传区域。
  • 图片预览：上传后原图显示在左侧预览区，显示原始尺寸。

二、设置目标尺寸

  • 自定义尺寸：在宽度/高度输入框中输入目标像素值。
  • 锁定比例：勾选"保持宽高比"后，修改任一值另一值自动按比例变化。
  • 预设尺寸：点击预设尺寸按钮可快速设置常见分辨率。

三、设置输出参数

  • 输出格式：选择缩放后的图片格式，默认为原始格式。
  • 图片质量：调整 JPEG 和 WebP 格式的输出质量（10%-100%）。

四、应用与下载

  • 应用缩放：点击"应用缩放"按钮执行缩放操作。
  • 对比预览：缩放后右图显示结果，原图保留在左侧方便对比。
  • 下载图片：点击"下载缩放图片"保存缩放后的图片到本地。

五、缩放原理

  • Canvas 缩放：利用 Canvas 的 drawImage 方法进行高质量图像缩放。
  • 抗锯齿：缩放过程中自动进行抗锯齿处理，保证图像质量。
  • 无损放大限制：放大图片时无法增加细节，建议缩放前评估结果。

注意事项

一、数据安全

  • 所有处理完全在本地浏览器中完成，数据不会上传到服务器。
  • 图片文件仅在浏览器内存中处理，关闭页面后自动清除。
  • 建议在处理敏感图片时使用隐私模式浏览。

二、尺寸限制

  • 放大图片时分辨率增加但不会增加细节，大比例放大后可能显示模糊。
  • 缩小图片时建议保持宽高比，避免图片变形。
  • 极小尺寸缩放可能导致文字和细节难以辨认。

三、格式说明

  • JPEG 格式不透明、体积小，适合输出照片类图片。
  • PNG 格式支持透明背景，适合图标和截图。
  • WebP 格式兼具较小体积和良好画质，现代浏览器均可支持。

四、常见问题

  • 缩放后图片模糊：小图放大时无法增加细节，建议使用原始大图缩放。
  • 宽高比不对：取消"保持宽高比"后手动输入目标宽高值。
  • 下载失败：检查浏览器下载权限设置。
  • 图片加载失败：检查图片格式是否正确或图片是否损坏。
