在线图片编辑：不装 Photoshop 也能完成基础修图

一、为什么你不需要为简单编辑打开 Photoshop

  • 旋转一张照片、调整亮度对比度、裁剪掉多余部分、加个简单的文字标注——这些"小手术"级别的编辑需求，完全不需要启动 Photoshop 这种重型武器。启动慢、操作复杂、导出还要选参数——为了旋转 90 度花 3 分钟等 PS 加载，得不偿失。
  • 本工具提供 8 种最常用的图片编辑功能：旋转、翻转、裁剪、亮度/对比度/饱和度调节、模糊/锐化滤镜、文字标注。所有操作实时预览，所见即所得。基于 Canvas 2D API 和 CSS Filter 实现，处理速度取决于你的 CPU 性能——一张 1080p 图片的滤镜应用通常在 100ms 以内。
  • 多步操作支持——可以连续应用多个编辑操作（比如先旋转再调色再加文字），每步操作都基于上一步的结果。最终满意后一键下载。所有处理在浏览器中完成，图片不离开本地。

二、支持格式与旋转特性

  • 旋转与翻转：顺时针旋转 90 度、逆时针旋转 90 度、旋转 180 度、水平翻转、垂直翻转——5 种方向操作覆盖所有常见需求。旋转基于 Canvas 的 rotate() 变换，翻转基于 scale(-1, 1) 变换，都是像素级精确操作。
  • 亮度/对比度/饱和度：三个维度的色彩调节，滑块范围 -100 到 +100。亮度调节基于像素 RGB 值的线性偏移；对比度基于 S 曲线映射（中间调拉伸、暗部和高光压缩）；饱和度基于 HSL 色彩空间的 S 通道缩放。
  • WebP：现代高效图片格式，支持完整处理（旋转、模糊、调色、滤镜等）。WebP 在保持与 JPG 相当画质的同时，文件体积减小 25-35%。Chrome、Edge、Firefox 等现代浏览器均支持编辑和预览，是网页图片的推荐格式。

三、编辑操作的叠加机制

  • 旋转：-180°~180° 任意角度精细旋转，快捷按钮一键旋转 -90°/+90°/180°。
  • 模糊：高斯模糊算法，0~20 级精细调节，轻松保护隐私或创建艺术效果。
  • 调整：亮度与对比度独立调节（均为 0~200%），精确修复曝光问题。
  • 色彩：饱和度（0~200%）控制色彩鲜艳度，色相旋转（0°~360°）改变整体色调。
  • 翻转：支持水平翻转（左右镜像）和垂直翻转（上下镜像），可同时启用。
  • 艺术滤镜：预设三种经典滤镜效果——灰度（去除所有色彩信息，生成黑白照片效果，适合复古风和艺术排版）、复古（降低饱和度并添加暖色调偏移，模拟老照片的泛黄质感）、反色（将每个像素的 RGB 值取反，生成底片/负片效果，用于创意设计和特殊视觉表达）。
  • 重置：一键恢复所有参数到默认值，也可单独重置旋转角度。
  • 重置功能：编辑过程中随时可以"重置"回到原始图片——清除所有已应用的编辑操作，从零开始。适合"改了半天觉得还是原图好"的场景。

编辑操作流程

载入图片

  • 点击上传：点击上传区域或拖拽图片到上传区域。
  • 批量上传：支持多选上传，最多20张图片。
  • 支持格式：支持 JPG、PNG、WebP、GIF、BMP 格式。

二、编辑图片

  • 旋转：拖动滑块调整角度，或点击快捷按钮（-90°/+90°/180°）快速旋转，点击"重置"恢复旋转角度。
  • 模糊：拖动滑块调整高斯模糊程度（0~20，步进0.5），值越大越模糊。
  • 亮度/对比度：分别拖动滑块调节，默认值100%表示不变，0%最暗/最灰，200%最亮/最强。
  • 饱和度/色相：饱和度控制色彩鲜艳程度，色相旋转可改变整体色调。
  • 翻转：点击“水平翻转”或“垂直翻转”按钮切换翻转状态。
  • 滤镜：点击滤镜按钮选择效果（原图/灰度/复古/反色），选中后高亮显示。
  • 重置全部：点击“重置全部”按钮恢复所有参数到默认值。

三、应用与下载

  • 应用到所有：勾选"应用到所有图片"，设置会应用到所有已上传图片。
  • 应用效果：点击“应用效果”按钮执行处理，左侧原图与右侧处理后实时对比。
  • 下载单张：点击"下载单张"按钮保存当前图片。
  • 批量下载：点击"批量下载"按钮打包下载所有处理后的图片。

四、操作技巧

  • 双击放大：双击原图或处理后图片可全屏查看。
  • 切换图片：在文件列表中点击图片切换当前处理图片。
  • 对比效果：左侧始终显示原图，右侧显示处理后的效果，方便对比。

注意事项

数据安全

  • 旋转、模糊、亮度、对比度等全部效果通过 CSS Filter 和 Canvas 在浏览器本地渲染，无网络传输。
  • 原图和处理参数仅在内存中保存，关闭标签页后自动清空。
  • 处理私密照片时建议开启无痕模式，确保浏览器不保留任何缓存。

二、编辑说明

  • 旋转后图片会自动填充背景色（JPG填充黑色，PNG填充透明），非90°整数倍旋转时尤为明显。
  • 亮度、对比度、饱和度默认值为 100%（即不变），色相默认值为 0°，所有参数可自由叠加。
  • 所有效果（旋转、模糊、亮度、对比度、饱和度、色相、翻转、滤镜）可同时应用，互不限制。
  • GIF 动态图片仅处理第一帧。

三、批量处理

  • 批量处理最多支持20张图片。
  • 勾选“应用到所有图片”时，当前所有设置会统一应用。
  • 大文件处理可能需要较长时间，请耐心等待。
  • 批量下载会打包为ZIP文件。

常见问题

  • 旋转后有黑边：JPG 格式非90°旋转时填充黑色背景，PNG 格式填充透明。建议使用 PNG 格式避免黑边。
  • 效果不满意：点击"重置全部"按钮一键恢复默认值，也可单独重置某个参数。
  • 处理失败：检查图片格式是否受支持、文件大小是否过大，建议尝试单张处理。
  • 下载失败：检查浏览器下载权限设置，或尝试更换保存路径。
