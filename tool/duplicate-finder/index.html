重复文件查找：用哈希算法精确识别重复内容

一、为什么需要重复内容查找工具

  • 多次下载同一份附件、不同文件夹保存了同一张照片的不同副本、备份时未去重导致数据翻倍——日积月累，重复文件可能占据 20%-40% 的存储空间。手动查找？文件名可能不同（如 report.pdf 和 report(1).pdf），内容却完全一样。本工具使用 SHA-256 哈希算法计算每个文件的"数字指纹"——只有内容完全相同的文件才会产生相同的哈希值。
  • 上传多个文件后，工具自动计算每个文件的 SHA-256 哈希值，然后按哈希值分组——相同哈希值的文件被标记为重复组。显示每组重复文件的数量、单个文件大小和浪费的总空间。支持一键下载去重后的文件集合。
  • 纯前端实现——文件哈希计算使用 Web Crypto API 的 SubtleCrypto 接口，在浏览器中完成所有计算。文件不上传到任何服务器。使用 Web Worker 并行计算哈希值，不阻塞主线程——即使处理大文件也能保持界面流畅。

二、哈希去重的技术原理

  • 自由文本：支持以空格、换行符、逗号、分号、顿号、管道符等常见分隔符分隔的文本内容。系统自动识别文本中使用的分隔符并正确拆分条目。例如"苹果，香蕉，苹果，橘子"会被拆分为 4 个条目，其中"苹果"出现 2 次。
  • 代码数据：支持从数组、列表等代码结构中提取值——如 [457,569,333,457,888] 会自动提取方括号内的数字并检测重复。也支持 JSON 数组、CSV 列值等结构化数据格式。

三、去重结果展示

  • 重复分组：相同内容的文件被分为一组——每组显示文件数量、单个文件大小和浪费的总空间（(数量-1) x 文件大小）。
  • 文件详情：每个文件显示文件名、大小和哈希值（前 16 位）。方便确认哪些文件是重复的。
  • 去重下载：每组重复文件中保留一份，其余标记为可删除。点击"下载去重结果"打包下载所有不重复的文件。
  • Web Worker 并行：哈希计算在 Web Worker 中执行——不阻塞主线程，处理过程中界面保持流畅。多个文件可以并行计算哈希值。

重复文件查找步骤

上传文件

  • 输入内容：在文本框中粘贴需要检测重复的内容。支持多种格式——逗号分隔的列表（a,b,c,a）、换行分隔的行列表、方括号内的数组（[1,2,3,1]）、空格分隔的单词等。
  • 示例格式：支持多种格式输入，如 [457,569,333,457,888] 或 你好，好啊，test，你好。系统自动识别分隔符并拆分条目——方括号、圆括号会被自动去除。
  • 自动识别分隔符：无需手动指定分隔符。系统自动识别文本中使用的分隔方式——空格、逗号、分号、顿号、管道符、句号、换行符等都可以作为分隔符。多种分隔符可以在同一段文本中混合使用。

二、支持的分隔符

  • 常见分隔符：空格、逗号(,)、分号(;)、顿号(、)、管道符(|)、句号(。)、问号(?)、感叹号(!)。
  • 括号：[]、()、【】、（）、《》、「」、『』。
  • 符号：下划线(_)、等号(=)、加号(+)、减号(-)、星号(*)、斜杠(/)、反斜杠(\)。
  • 其他：换行符、制表符、波浪号(~)、@、#、$、%、^、&。

三、查找重复内容

  • 点击查找：点击"查找重复内容"按钮开始检测。
  • 快捷键：Ctrl+Enter 快捷触发查找。
  • 统计信息：显示总项数、唯一项数、重复项数。

四、查看结果

  • 重复标签：显示所有重复内容及其重复次数。
  • 点击筛选：点击重复标签可以筛选只显示该重复项。
  • 高亮预览：在原文中高亮显示所有重复内容。
  • 不同颜色：不同重复内容用不同颜色高亮标记。

五、操作技巧

  • 清空文本：点击"清空"按钮清除所有输入内容。
  • 再次点击：在高亮预览中点击重复项标签取消筛选。
  • 复制结果：直接选中文本复制高亮预览内容。

注意事项

数据安全

  • 纯前端处理：文件哈希计算完全在浏览器中完成——文件内容不上传到任何服务器。
  • 内存管理：大文件分块读取，不会一次性加载到内存。处理完成后自动释放内存。
  • 数据清除：关闭页面后所有文件数据和哈希值自动清除。

二、分隔符处理

  • 工具会自动识别多种分隔符，无需手动指定。
  • 标点符号会被自动去除，只比较核心内容。
  • 中英文标点均支持，如逗号和中文逗号。

三、匹配规则

  • 不区分大小写，"Test"和"test"视为相同。
  • 去除前后空格后比较。
  • 去除标点符号后比较，"你好。"和"你好"视为相同。

二、性能说明

  • 检测算法基于 JavaScript Map 数据结构，时间复杂度为 O(N)——即使 10 万条目也能在 100 毫秒内完成检测。不存在性能瓶颈。
  • 高亮预览功能需要在原文中查找所有重复项的位置并添加颜色标注——对于超长文本（超过 10 万字符），高亮渲染可能需要 1-2 秒。这是浏览器 DOM 操作的性能限制，不影响检测结果的准确性。
  • 建议单次检测的文本不超过 1MB。超大文本可能导致浏览器内存占用过高。对于超大数据集的去重，建议使用命令行工具（如 sort | uniq -d）或数据库查询。

常见问题

  • Q: 两个文件大小相同但内容不同，会被误判为重复吗？A: 不会。哈希算法基于文件内容，不是文件大小。内容不同则哈希值不同。
  • Q: 能查找整个硬盘的重复文件吗？A: 不能。本工具只能处理你手动上传的文件——无法访问文件系统。
  • Q: 处理速度很慢？A: 哈希计算速度取决于文件大小和数量。SSD + 现代 CPU 环境下，100 个 10MB 文件约需 10-30 秒。
