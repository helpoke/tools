工具介绍

汇总这件事，卡在"为跑一次数据开一堆东西"

  • 手上有一份导出好的 CSV，想按地区看销售额、按渠道看订单数。平时这条路是：要么开 Excel 拖数据透视表（公司电脑没装、Mac 上 Numbers 对不上、几十兆文件卡半天），要么写一段 pandas groupby（为一次汇总装几百兆环境），要么在数据库里 GROUP BY（可数据就在桌面上，没导进去）。
  • 更麻烦的是细节：金额列写成 1,234.50 或带 ¥，Excel 会把整列识别成文本、求和结果是 0；表头有空格或大小写不一致，公式引用起来对不上；引号里含逗号与换行的字段被朴素的 split(',') 切碎，汇总口径悄悄变了却看不出来。
  • 交叉表是另一类高频需求：行是地区、列是月份、格里放销售额。手工在表格里转置一遍既慢又容易漏掉"某地区某月没有数据"这种空格子与合计行的对账。

核心功能

  • 分组聚合：支持同时选多个分组列，聚合可选计数、去重计数、求和、平均、最大、最小、首末值、文本拼接，等价于浏览器里跑一次 GROUP BY；引号包裹与字段内换行按标准 CSV 规则解析。
  • 交叉透视：指定行字段、列字段、值字段与算法，自动生成矩阵，列值按数值优先排序，可加行合计与列合计；"某组合没有数据"的空格与真实为 0 的格子区分处理。
  • 数值容错与可核对的输出：自动识别分隔符，剔除千分位逗号、货币符号、百分号与空格后再计算，非数值单元格跳过并在提示区计数；结果可输出为带 BOM 的 CSV、JSON 数组或 Markdown 表格，直接贴进文档与工单。

使用说明

  1. 把 CSV 粘到左侧（或上传文件）。列名会在"分组列"里自动出现，点击列名即可选择分组维度，选中先后就是层级先后。
  2. 在"聚合列"里选算法与列，点"添加"，可加多个；不选任何聚合列时默认输出每个分组的计数。
  3. 点"汇总"看结果，按需切换排序、小数位、只看前 N 行与输出格式；要做交叉表就把"汇总方式"切成透视表，指定行、列、值三个字段。

注意事项

  • "求和 / 平均 / 最大 / 最小"只统计能解析成数字的单元格：1,234.50、¥99、12% 会分别按 1234.5、99、12 计算（百分号只去符号、不除以 100）；-、N/A、空串与被识别为文本的值计入跳过数并在提示区给出，绝不会当成 0 拉低平均值。
  • 分组的键区分大小写、不做全半角归一、只去掉首尾空格：华东 与 华东 会被分成两组，导出前建议先用文本处理工具清洗。
  • 透视表的列数取决于列字段的去重值个数，列值过多（如用日期或订单号当列字段）会生成很宽的表；超过 200 个列值时只取前 200 个并在提示区说明。
  • 计数与去重计数不要求值是数字；"拼接文本"每个分组最多保留前 50 个值，超出以 … 结尾，防止结果单元格过长。
  • 单次建议不超过 200000 行、文件不超过 20MB；解析与汇总在主线程同步完成，大文件会有几秒停顿。不联网、不上传，关闭页面即清除全部内容。

典型场景

  • 订单报表核对：按"地区"汇总"金额"，再看每个地区的订单数与客单价，确认给领导的数字与自己算的一致。
  • 日志分析：按状态码或接口路径分组计数，一眼看出哪个 5xx 集中在哪条链路上。
  • 交叉表出周报：行是渠道、列是月份、格内是销售额，附行列合计，直接贴进周报或 Markdown 文档。
  • 数据清洗前置：用"去重计数"看某列的基数（用户数、SKU 数），判断是否需要在入库前建索引或做字典表。
  • 对账辅助：两边各跑一次分组求和，比对分组合计的差额落在哪个维度上，比逐行 diff 快得多。
