表格转 SQL INSERT

查看详细使用文档与 FAQ 返回首页

支持粘贴或上传 Excel(.xlsx)/CSV 文件，把 CSV / TSV / Excel 表格一键生成 INSERT INTO 语句，支持 MySQL / PostgreSQL、批量分块、空值转 NULL、日期规范与建表预览

*（所有处理完全在您本地浏览器中完成，本站绝不收集、不存储、不传播、不上传您的任何数据文件）

工具介绍

                

                

                    
表格数据直接变成可执行的插入语句

                    
    
                        
  • 手上有一份 CSV 或 Excel 表格要导入数据库，手写 INSERT
                            又慢又容易漏引号、错转义。粘贴进来一键生成规范的 INSERT INTO 语句，复制即用。
    • 
                        
  • 自动做类型判断与转义：纯数字不加引号，字符串加引号并正确转义单引号与反斜杠，从源头上避免 SQL
                            语法错误和注入风险。
    • 
                        
  • 生成过程全在浏览器本地完成，数据表不会上传到任何服务器，可用 F12 的 Network 面板验证。
                        
    • 
                    

                    
核心功能

                    
    
                        
  • 双方言支持：MySQL 用反斜杠/单引号转义与反引号标识符，PostgreSQL
                            用双单引号转义与双引号标识符。
    • 
                        
  • 批量分块：设置每批行数可将多行合并进一条多值 INSERT（VALUES (...),(...)），0
                            表示每行一条，减小脚本体积与执行开销。
    • 
                        
  • 灵活选项：是否输出列名、空单元格是否转 NULL、标识符是否加引号、分隔符自动识别，兼顾不同建表习惯。
                        
    • 
                        
  • 日期规范：自动将日期时间值统一为 yyyy-mm-dd hh:mm:ss，Excel 上传的日期序列号也会自动还原为真实日期。
    • 
                        
  • 建表预览：根据数据自动推断字段类型，在下方生成 CREATE TABLE 语句并以表格形式预览填好的数据，可一键复制。
    • 
                    

                

            


            

                

                    
使用说明

                

                

                    
    
                        
  1. 把 CSV/TSV 或从 Excel
                            复制的表格粘贴到左侧输入框（首行放列名），或点击"载入示例"。
    2. 
                        
  2. 填写目标表名，选择方言（MySQL / PostgreSQL）与分隔符，按需设置每批行数。
                        
    3. 
                        
  3. 勾选是否输出列名、空值转 NULL、标识符加引号，点击"生成 SQL"。
    4. 
                        
  4. 复制或下载生成的 INSERT 语句，直接在数据库中执行导入。
    5. 
                    

                

            


            

                

                    
注意事项

                

                

                    
    
                        
  • 生成语句仅做值转义与语法拼装，不会替您校验表结构；执行前请确认列数、类型与目标表一致。
    • 
                        
  • 数字判定较保守：仅整体为数字时才去引号，带前导零（如 007）、单位或空格的会当字符串处理，避免破坏编码。
                        
    • 
                        
  • 本工具生成的是纯文本 SQL，不会连接或写入任何数据库；请在可信环境执行，并做好备份。
    • 
                    

                

            


            

                

                    
典型场景

                

                

                    
    
                        
  • 初始化数据：把配置表、字典表 CSV 转成 INSERT 脚本，随建表 SQL 一起纳入版本管理。
                        
    • 
                        
  • 快速导库：客户给了 Excel 名单，临时要入数据库，直接粘贴生成 INSERT，省去写导入脚本。
                        
    • 
                        
  • 数据修复：手工整理几行更正数据后转成 INSERT/补录语句，在事务里执行并核对影响行数。
    • 
                        
  • 测试造数：配合"模拟数据生成器"生成的表格，转成 INSERT 灌入测试库，快速铺底数据。
    • 
                        
  • 跨库迁移辅助：选择对应方言生成，规避不同数据库的引号与转义差异，降低手工改写成本。
