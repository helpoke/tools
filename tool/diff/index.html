文本比对：逐行逐字找出两段文本的差异

一、解决的问题

  • 两段代码哪里不一样？合同 V1 和 V2 改了什么？翻译稿和原文有哪些出入？配置文件修改了哪个参数？这些场景都需要精确的文本比对——肉眼逐行扫描不仅慢，还极易遗漏。本工具基于经典的 Myers 差异算法，精确到行级别地标识新增、删除和修改的内容。
  • 将两段文本分别粘贴到左右输入框，点击"比对"按钮后立即看到差异结果——新增内容绿色高亮、删除内容红色高亮、修改内容黄色标注。支持忽略空白差异和大小写差异——适应不同场景的比对需求。
  • 纯前端实现——文本比对在浏览器中完成，不上传到任何服务器。支持任意长度的文本比对（受浏览器内存限制，通常可以处理数万行的文本）。比对结果可以一键复制或直接查看。

二、差异算法的工作原理

  • 文本：支持该格式的完整处理功能。
  • 代码：支持该格式的完整处理功能。

三、比对结果的呈现方式

  • 并排视图：左右两栏分别显示原始文本和比对文本——差异行用颜色高亮标注，对齐显示方便逐行对比。
  • 颜色编码：绿色 = 右侧新增的行、红色 = 左侧删除的行、黄色 = 修改的行（左右都有但内容不同）、灰色 = 未变化的上下文行。
  • 统计信息：比对完成后显示差异统计——新增行数、删除行数、修改行数、总差异数。快速了解两段文本的差异程度。
  • 纯本地处理：文本比对完全在浏览器中完成——你的代码、合同、配置等敏感内容不会上传到任何服务器。

文本比对操作步骤

输入文本

  • 直接输入：在左侧"原始文本"和右侧"新文本"输入框中输入或粘贴内容。
  • 上传文件：点击"打开文件"按钮选择本地文本文件（支持 .txt, .json, .xml, .html, .css, .js, .ts, .md 等）。
  • 文件格式：仅支持纯文本文件，不支持二进制文件（图片、PDF、压缩包等）。

二、对比选项

  • 显示相同行：勾选后显示所有行，包括没有变化的行。
  • 逐词对比：勾选后在差异行中高亮显示具体变化的词语。
  • 交换文本：点击⇄按钮交换左右两侧文本内容。

三、查看差异

  • 点击对比：点击"开始对比"按钮执行文本差异比对。
  • 实时对比：文本变化时自动触发对比（500ms延迟）。
  • 新增行：绿色背景，以"+"开头，表示新文本中新增的行。
  • 删除行：红色背景，以"-"开头，表示原始文本中删除的行。
  • 修改行：黄色背景，表示两行内容有差异。
  • 统计信息：显示新增、删除、相同的行数统计。

四、操作技巧

  • 清空文本：点击"清空"按钮清除所有输入内容。
  • 复制结果：直接在差异结果中选中文本复制。
  • 键盘快捷键：Enter键触发对比。

五、适用场景

  • 代码对比：比较代码版本之间的差异。
  • 文档对比：检查文档修改前后的变化。
  • 配置对比：对比配置文件的差异。
  • 日志对比：分析日志文件的变化。

注意事项

数据安全

  • 纯前端处理：文本比对完全在浏览器中完成——代码、合同等敏感内容不会离开本地。
  • 无数据存储：不保存任何比对历史——关闭页面后所有数据清除。
  • 无网络请求：比对过程不产生任何网络请求——离线也能正常使用。

二、文件限制

  • 仅支持纯文本文件，不支持二进制文件。
  • 支持的文件扩展名：.txt, .csv, .json, .xml, .html, .css, .js, .ts, .md, .log, .yml, .yaml, .sql 等。
  • 大文件处理可能需要较长时间，请耐心等待。

二、性能提示

  • 建议单次对比的文本不超过 10000 行。超大型文本（数万行）的 diff 计算可能需要较长时间并占用较多内存。对于大型文件的对比，建议使用命令行工具（如 Git diff 或 diff 命令）。
  • 对比计算在浏览器主线程中执行——计算期间页面可能暂时失去响应。大文本对比会自动延迟执行（使用 requestIdleCallback），避免阻塞用户交互。处理期间请勿关闭浏览器或刷新页面。
  • 文件上传功能仅支持文本文件（UTF-8 编码）。二进制文件（如 .exe、.jpg、.pdf）无法正确读取为文本进行对比。上传非文本文件会提示"不支持此文件类型"。

四、编码处理

  • 支持UTF-8编码的文本文件。
  • 其他编码可能导致乱码，建议转换为UTF-8后再对比。

常见问题

  • Q: 比对结果太多看不清？A: 尝试勾选"忽略空白"——很多差异其实只是空格和空行的不同，忽略后差异量大幅减少。
  • Q: 能比对两个文件吗？A: 先将文件内容复制粘贴到输入框中。当前版本不支持直接上传文件比对。
  • Q: 比对结果能导出吗？A: 当前版本不支持导出为 diff 文件格式。可以截图保存或使用浏览器打印为 PDF。
  • 性能问题：减少文本内容或分段对比。
