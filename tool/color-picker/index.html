颜色选择器：从色轮到代码的精确色彩转换

一、颜色表示法的"方言"问题

  • 设计师在 Photoshop 里用 HSL 调色，前端工程师在 CSS 里写 HEX，Python 脚本需要 RGB 元组，Java 的 Color 类需要 0-255 整数——同一种颜色在不同工具和语言中有完全不同的表示方式。手动转换不仅繁琐，还容易出错——把 #3B82F6 手动转成 RGB 是多少？大多数人算不对。
  • 本工具提供全方位的颜色选择与转换功能：可视化色轮取色、HEX/RGB/HSL/HSV/CMYK 五种格式实时互转、CSS 渐变生成器、调色板提取工具。在色轮上点击任意位置，五种格式的颜色值同时更新——不需要手动输入或计算。
  • 支持从 HEX 值反向选色——输入一个颜色代码，色轮自动定位到对应位置。也支持随机生成和谐配色方案（互补色、三色组、四色组、类似色）——帮助设计师快速找到协调的色彩搭配。

二、五种颜色格式的技术背景

  • HEX：支持该格式的完整处理功能。
  • RGB：支持该格式的完整处理功能。
  • HSL：支持该格式的完整处理功能。

三、核心功能详解

  • 可视化色轮：在 HSL 色轮上点击或拖动取色——色轮外圈是色相（H），内部是饱和度（S）和亮度（L）的二维平面。比输入数字更直观——看到什么颜色就点什么位置。
  • 五色值同步：选择任何颜色后，HEX、RGB、HSL、HSV、CMYK 五种格式同时显示并支持一键复制。修改任一格式的值，其他格式自动同步更新。
  • CSS 渐变生成器：选择两种或多种颜色，自动生成 linear-gradient 或 radial-gradient 的 CSS 代码。实时预览渐变效果，支持调整角度和颜色停靠点。
  • 和谐配色方案：基于色轮角度关系自动生成配色——互补色（180° 对角）、三色组（120° 等分）、四色组（90° 等分）、类似色（±30° 邻近）。帮助快速找到协调的色彩搭配。

颜色选择操作流程

一、选择颜色

  • 点击色块：点击左侧颜色预览块打开系统颜色选择器。
  • 拖动选择：在颜色选择器中拖动选择所需颜色。
  • 预设颜色：点击下方常用颜色快速选择。

二、HEX格式

  • 十六进制：以#开头，由6位十六进制数字组成（0-9, A-F）。
  • 输入方式：直接输入6位颜色值，自动转换为大写。
  • 简写支持：支持3位简写（如#FFF），自动扩展为6位。
  • 复制：点击"复制"按钮复制完整HEX值。

三、RGB格式

  • 红绿蓝：由红、绿、蓝三个分量组成，每个分量0-255。
  • R值：红色分量，0表示无红色，255表示最大红色。
  • G值：绿色分量，0表示无绿色，255表示最大绿色。
  • B值：蓝色分量，0表示无蓝色，255表示最大蓝色。
  • 复制：点击"复制"按钮复制rgb(r, g, b)格式。

四、HSL格式

  • H色相：颜色的种类，取值0-360度（红色0°，绿色120°，蓝色240°）。
  • S饱和度：颜色的纯度，0%-100%（0%为灰色，100%为纯色）。
  • L亮度：颜色的明暗，0%-100%（0%为黑色，50%为正常，100%为白色）。
  • 复制：点击"复制"按钮复制hsl(h, s%, l%)格式。

五、格式转换

  • 实时转换：修改任意格式的值，其他格式自动同步更新。
  • 互相转换：三种格式完全等价，可以任意转换。
  • 复制全部：点击"复制全部格式"按钮一次性复制三种格式。

五、色彩设计建议

  • 60-30-10 法则：主色占 60%（背景）、辅色占 30%（内容区域）、强调色占 10%（按钮/链接）。这是最经典的比例分配。
  • 对比度检查：文字颜色与背景色的对比度至少 4.5:1（WCAG AA 标准）——确保可读性。白色文字配浅灰色背景是常见的可读性灾难。
  • 色盲友好：避免仅用红绿差异传达信息——红绿色盲是最常见的色觉缺陷（约 8% 男性受影响）。使用形状/文字辅助区分。

注意事项

数据安全

  • 纯前端工具：所有颜色计算在浏览器中完成——不上传到任何服务器。
  • 无网络依赖：页面加载完成后离线也能正常使用。
  • 无数据存储：不保存你的颜色选择历史——每次打开都是全新开始。

格式转换说明

  • HEX 与 RGB：直接对应——HEX 的每两位就是 RGB 一个通道的十六进制值。#FF0000 = RGB(255, 0, 0)。
  • RGB 与 HSL：需要数学转换——HSL 的色相由 RGB 三通道中最大值和最小值的差决定，饱和度和亮度由最大值和最小值的和决定。
  • RGB 与 CMYK：CMYK 是减色模型（油墨吸收光线），RGB 是加色模型（屏幕发射光线）。两者不能完美对应——某些鲜艳的 RGB 颜色在 CMYK 中无法精确再现。
  • 色域限制：屏幕显示的是 sRGB 色域，CMYK 印刷色域不同——屏幕上看到的颜色和实际印刷效果可能有差异。重要项目建议打样确认。

常见问题

  • Q: 颜色在手机上看起来不一样？A: 不同设备的屏幕色域和色彩校准不同——同一颜色在 iPhone 和 Android 上可能有差异。设计时以 sRGB 标准为准。
  • Q: 能输入颜色名称吗？A: 当前版本不支持 CSS 颜色名称（如 red、blue）。请直接输入 HEX 或 RGB 值。
  • Q: 渐变色代码在旧浏览器中不生效？A: CSS gradient 需要添加浏览器前缀（-webkit-, -moz-）。现代浏览器（2020 年后）已不需要前缀。
