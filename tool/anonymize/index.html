工具介绍

分享数据前，先抹掉隐私

  • 截图里的手机号、日志中的身份证号、要发到群里的客户名单、贴到提问区的报错信息——直接转发极易泄露隐私。本工具自动识别常见敏感字段并一键打码，脱敏后再分享。
  • 支持掩码、哈希、泛化三种脱敏策略：想给人看清"打码了"用掩码；要保持同一号码脱敏后仍一致可关联，用哈希；只想保留大致范围（如 IP 网段），用泛化。
  • 识别、替换全部在浏览器本地完成，敏感原文不会上传到任何服务器，可用 F12 的 Network 面板验证。

核心功能

  • 多类型识别：中国大陆手机号、固定电话、18/15 位身份证、16-19 位银行卡、电子邮箱、IPv4 地址，可按类型勾选开关。
  • 三种脱敏方式：掩码（首尾保留位数可调）、哈希（同值同码、便于关联分析）、泛化（保留前缀/量级，隐藏精确值）。
  • 通用文本处理：既能整段散文，也能 CSV/TSV 表格，逐类型统计替换数量，结果复制或下载即用。

使用说明

  1. 把需要脱敏的文本或 CSV/TSV 数据粘贴到左侧输入框，或点击"载入示例"体验。
  2. 勾选需要处理的敏感类型，选择脱敏方式（掩码/哈希/泛化），并可调整掩码字符与首尾保留位数。
  3. 点击"开始脱敏"，右侧生成脱敏后的文本，下方统计各类替换数量。
  4. 核对无误后复制或下载结果，再用于分享、存档或提 Bug。

注意事项

  • 识别基于正则模式，纯数字串可能被银行卡/手机号规则同时命中；处理后请务必人工抽查关键结果，重要合规场景请以专业脱敏系统为准。
  • 哈希方式为可逆性较低的短摘要（非密码学加盐），用于保持"同值同码"的关联性；如需不可追溯请使用掩码或配合密钥。
  • 本工具面向中国大陆常见格式（手机号 1[3-9] 开头、18 位身份证等）；其他地区的号码格式可能不被识别。

典型场景

  • 报障贴文：把报错日志里的用户手机号、身份证、IP 一键打码后再发到技术社区求助，不泄露他人隐私。
  • 名单分享：客户/员工表格导出后需要跨部门流转，先脱敏身份证与银行卡，保留可读姓名与城市。
  • 演示数据：把生产数据脱敏成"看起来真实但不含真实隐私"的样例，用于培训、演示或测试环境。
  • 日志分析：用哈希方式把用户 ID 转成稳定的替身码，既能做去重与关联统计，又不暴露真实身份。
  • 合规自查：截图或文档发布前快速扫一遍，把残留的邮箱、卡号等 PII 打码，降低违规风险。
