数据统计器 - 使用说明与 FAQ

粘贴或上传 Excel(.xlsx)/CSV 数据，本地计算均值、中位数、众数、方差、标准差与分位数，并以直方图/箱线图可视化分布

什么是数据统计器？

数据统计器是一款免费的在线描述性统计助手。手头有一列成绩、销售额、响应时间，想快速了解它的整体水平与波动情况，开 Excel 或写脚本都太重。粘贴进来即可一次得到十余项常用统计量，还能对整张表逐列出摘要。

工具会自动识别数值列，把带单位、千分位、货币符号等无法解析为数字的内容剔除并单独计数，避免"一个脏数据毁掉一次计算"。全部逻辑在浏览器本地运行，Excel 解析也使用站内本地脚本完成，不依赖任何在线计算服务。

能算哪些统计量？

集中趋势：

  • 算术均值：所有有效数值之和除以个数。
  • 中位数：排序后居于中间位置的值，抗极端值干扰。
  • 众数：出现次数最多的值，多个同频时全部列出。

离散与分布：

  • 极差、总体/样本方差、总体/样本标准差。
  • 四分位数 Q1 / Q3 与 IQR，P10 / P90 等分位数。
  • 计数 / 求和 / 最小值 / 最大值，以及非数值、空值的剔除计数。

如何快速开始？

第一步：粘贴或上传数据

一列数字（每行一个，或空格/逗号分隔）直接粘贴即可；也可点击"上传 Excel/CSV"加载 .xlsx / .csv / .txt 文件，多列 CSV/TSV（含从 Excel 复制粘贴）同样能识别。

第二步：选择统计列

设置分隔符与"首行为表头"，在"统计列"里选择全部数值列或指定某一列，并设置结果小数位。

第三步：统计并取用

点击"统计"生成报告，右侧显示数值个数×列数；下方同步展示直方图 + 箱线图与关键指标卡片，多列时可点标签切换；报告可复制或下载为文本文件，粘进表格继续分析。

典型应用场景

成绩考核：一列分数快速看平均分、中位数与标准差，判断整体水平与离散程度。

运营指标：对订单量、转化率序列求均值与 IQR，识别指标波动与异常周。

性能分析：用 P90/P99 分位数评估接口长尾延迟，比平均值更贴近真实体验。

数据预处理：入库前逐列看计数、缺失与范围，及早发现脏数据与量纲问题。

特点与优势

本地计算，保护隐私 无需注册，即用即走 自动识别数值列 总体 / 样本双口径 任意分位数 多列逐列出摘要 Excel/CSV 文件上传 直方图 + 箱线图 一键复制与下载

注意事项：

  • 只有能整体解析为数字的单元格才参与统计，带单位/千分位/文字的会被剔除并计数。
  • 方差与标准差同时给出总体（÷n）与样本（÷n-1）两种口径，按数据是"全部"还是"抽样"选择。
  • 样本量过小（如 n<4）时四分位数与 P90 仅供参考，波动较大。
  • 数据在浏览器本地处理，不会上传服务器，公共设备建议配合无痕模式。

常见问题

问：总体标准差和样本标准差该看哪个？

答：数据就是研究对象全体时用总体口径（÷n）；由样本估计更大总体用样本口径（÷n-1），结果略大。质检、抽样统计多用样本。

问：为什么有些数字没被算进去？

答：带单位（12kg）、千分位（1,200）、货币符号或混排文字无法整体解析为数字，会被"非数值剔除"计数排除。建议先在源数据去掉单位。

问：多列 CSV 能一起统计吗？

答：可以。勾选"首行为表头"并让"统计列"保持"全部数值列"，工具会对每个数值列各输出一份摘要，用空行分隔。

问：分位数是怎么算出来的？

答：采用线性插值法（与 numpy/pandas 默认一致），排序后按位置 (n-1)×p 在相邻样本间插值，结果更平滑。

问：可以上传 Excel 文件吗？

答：可以。点击"上传 Excel/CSV"选择 .xlsx / .csv / .txt，Excel 在本地解包读取第一个工作表后自动填入输入框并统计，不上传服务器；旧版 .xls 请先另存为 .xlsx。

问：图表里的箱线图怎么看？

答：箱体两端是 Q1/Q3，粗线是中位数，须线延伸到 1.5×IQR 范围内的最远值，超出部分以圆点标出即离群点，与上方直方图共享横轴，可对照着看分布形态与异常值。

问：一列里混了个别非数字会怎样？

答：只有能整体解析为数字的单元格参与计算，个别带单位/文字的值会被归入“非数值剔除”并单独计数，不影响其余数值的均值与方差；若一列中数字不足非空单元格的一半，则不会被判为数值列。

使用最佳实践

  • 先看计数与剔除：有效数值个数与非数值剔除数对不上，说明数据里混入了单位或空行，应先清洗。
  • 均值 vs 中位数看偏斜：两者差距大通常意味着有极端值或分布偏斜，此时中位数更能代表典型水平。
  • 用 IQR 找离群点：低于 Q1-1.5×IQR 或高于 Q3+1.5×IQR 的值常被视为异常，可回源核查；箱线图上的圆点就是这些离群值，可可视化直接定位。
  • 配合 CSV 工具箱：需要先去重、排序、转置时，可在"CSV 工具箱"处理后把结果再粘进统计器。
  • 本地处理：敏感业务数据全程在浏览器完成，关闭页面即清除。
