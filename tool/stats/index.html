工具介绍

一列数字，秒出完整统计摘要

  • 手头有一列成绩、销售额、响应时间，想快速知道平均值、最高最低、有没有异常值？开 Excel 或写脚本都太重，本工具粘贴即算，一次给出十余项常用统计量。
  • 自动识别数值列，非数字与空值自动剔除并单独计数，避免“一个脏数据毁掉一次计算”，也不会把 0 当成空值漏算。
  • 所有计算在浏览器本地完成，敏感的业务数据不会上传到任何服务器，可用 F12 的 Network 面板验证。

核心功能

  • 集中趋势：算术均值、中位数、众数（多峰自动全部列出），一眼看清数据的典型水平与最常见取值。
  • 离散程度：极差、总体与样本方差、标准差、四分位距 IQR，帮助判断数据是否稳定、有无离群点。
  • 分位数：Q1 / Q3 / P90 等任意百分位，配合多列分别统计，可对整张表逐列出一份摘要。
  • 可视化与文件：直方图叠加箱线图直观展示分布形态与离群点，关键指标卡片化呈现；支持直接上传 Excel(.xlsx)、CSV、TXT 文件。

使用说明

  1. 把数据粘贴到左侧输入框，或点击“上传 Excel/CSV”直接加载 .xlsx / .csv / .txt 文件：可以只有一列数字（每行一个，或空格/逗号分隔），也可以是带表头的 CSV/TSV（可从 Excel 复制）。
  2. 选择分隔符（默认自动识别）与“首行为表头”；“统计列”可选全部数值列或指定某一列。
  3. 设置结果保留的小数位，点击“统计”，右侧生成完整统计报告。
  4. 复制或下载报告，也可直接下载为 CSV 摘要文件，粘进表格或文档继续分析。

注意事项

  • 只统计能被完整解析为数字的单元格；带单位、千分位逗号或货币符号的内容会被视为非数值并剔除计数。
  • 方差/标准差同时给出“总体”与“样本”两种口径：数据是全部对象用总体，抽样估计用样本（除以 n-1）。
  • 分位数采用线性插值法（与多数统计软件默认口径一致）；样本量过小（如 n<4）时四分位数仅供参考。

典型场景

  • 成绩与考核：粘贴一列分数，立刻得到平均分、及格线附近的中位数、分布是否偏斜（均值 vs 中位数）、最高最低与标准差。
  • 运营指标：对日订单量、客单价、转化率序列求均值与波动（标准差/IQR），判断指标是否稳定。
  • 性能分析：把接口响应时间列表粘进来，用 P90/P99 分位数评估长尾延迟，比平均值更能反映体验。
  • 财务核对：一列金额快速求和、找极值与众数（重复出现的异常金额），配合去重排查问题账单。
  • 数据预处理：入库前先逐列看计数、缺失（非数值）与分布范围，及时发现脏数据与异常量纲。
