什么是模拟数据生成器？

模拟数据生成器是一款免费的在线造数据工具。开发联调接口、演示表格组件、验证导入导出功能时，总需要一批"看起来像真的"的数据。手写费时，网上找的样例库又未必贴合字段——本工具让你像点菜一样勾选字段，一次生成最多 1000 条结构化记录。

工具内置 16 种常用字段模板：自增 ID、中文姓名、英文姓名、性别、手机号、邮箱、地址、日期、日期时间、时间戳、随机整数（范围可配）、随机小数、布尔值、UUID、IP 地址、颜色值。字段名即 JSON 键名（id / name / phone / email …），生成即可用。全部随机数在浏览器本地生成，不请求任何接口。

支持的输出格式

  • JSON 数组：标准 [{...}, {...}] 结构，带缩进，可直接粘进前端代码或接口 Mock。
  • CSV：首行为英文字段名表头，文本含逗号/引号时自动按 RFC4180 加引号转义，可导入 Excel 或数据库。
  • JSON Lines：每行一个独立 JSON 对象，适合日志系统、流式处理与按行解析场景。

如何快速开始？

第一步：勾选字段模板

默认已勾选 ID、姓名、性别、手机号、邮箱、随机整数六个常用字段；可用"全选字段 / 清空选择"快捷操作，或按需单独勾选。

第二步：设置条数与格式

填写生成条数（1~1000），选择输出格式；若勾选了随机整数，可先配置取值范围（默认 1~100）。

第三步：生成并取用结果

点击"生成数据"，结果出现在右侧输出区；点击"复制"取用文本，或"下载"得到 .json / .csv / .ndjson 文件。再点一次即可换一批。

典型应用场景

接口联调：生成字段齐全的用户列表 JSON，前端先跑起来，后端接口就绪后无缝替换。

组件演示：给表格、图表组件喂一批带姓名/日期/数值的演示数据（CSV 可直接粘进"数据转图表"工具）。

导入测试：导出 CSV 验证系统的批量导入、去重、字段校验逻辑。

压力占位：批量生成 UUID、IP、时间戳，填充缓存或消息队列的测试报文。

特点与优势

本地生成，保护隐私 无需注册，即用即走 16 种字段模板 单次最多 1000 条 JSON / CSV / JSON Lines 整数范围可配置 一键复制与下载

注意事项：

  • 生成的数据均为随机虚构值，请勿当作真实用户数据使用，也不要用于伪造身份、虚假注册等违规用途。
  • 自增 ID 每次点击"生成数据"都从 1 重新开始；跨批次需要唯一主键时建议改用 UUID 字段。
  • 日期与时间戳在近三年内随机分布；布尔值只有 true / false 两种取值。
  • 一次最多生成 1000 条，更大规模建议分批生成后合并文件。
  • 数据在浏览器本地生成，不上传服务器，仍建议在安全环境中操作。

常见问题

问：生成的手机号是真实号码吗？

答：不是。手机号从公开号段随机拼接 11 位数字，符合格式规律但不指向任何真实机主，仅供测试使用。

问：能让两次生成的数据一样吗？

答：工具不提供随机种子功能。需要稳定的数据集时，生成后立即下载保存，之后反复使用同一份文件。

问：CSV 打开后中文乱码怎么办？

答：下载的文件为 UTF-8 编码。用 Excel 直接双击打开旧版 CSV 可能识别错编码，建议通过"数据 → 从文本导入"并选择 UTF-8。

问：可以自定义字段名吗？

答：暂不支持。当前版本字段名固定为英文键名（id / name / phone / email 等），生成后可在代码或"CSV 工具箱"中做二次处理。

使用最佳实践

  • 先小批后大批：先按 10 条确认字段组合与格式符合预期，再放大到 1000 条。
  • UUID 代替自增 ID：多批次数据合并去重时，UUID 字段可保证主键不冲突。
  • 配合 CSV 工具箱：生成的 CSV 可在"CSV 工具箱"里继续做排序、去重、转格式。
  • 配合数据转图表：带日期与随机整数的 CSV 粘进"数据转图表"即可快速演示可视化效果。
  • 及时下载留存：每次点击都会重新随机，满意的结果请立即复制或下载。
