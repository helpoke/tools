什么是模拟数据生成器？

模拟数据生成器是一款免费的在线造数据工具。开发联调接口、演示表格组件、验证导入导出功能时，总需要一批"看起来像真的"的数据。手写费时，网上找的样例库又未必贴合字段——本工具让你像填表一样定义字段结构，一次生成最多 1000 条结构化记录。

工具内置 45+ 种常用字段类型，按基础/标识/地理/企业/时间/网络/文本分组：中文/英文姓名、性别、手机号、邮箱、地址、身份证（带校验位）、银行卡（Luhn 合法）、公司、职业、经纬度、URL、段落等。每行字段由"路径 + 类型 + 配置"三部分组成，路径即输出键名，可自由命名。全部随机数在浏览器本地生成，不请求任何接口。

字段路径与多层嵌套

  • name：普通顶层字段，直接作为 JSON 键名。
  • profile.city：点号分层，生成嵌套对象；层级不限，如 user.address.geo.lat。
  • tags[]：[] 后缀表示数组，元素长度由工具条"数组长度"控制。
  • orders[].sku、orders[].items[].qty：对象数组及数组套数组；共用同一路径前缀的行会合并到同一元素内。

自定义字段

  • 枚举：配置列填候选值（逗号分隔），每次随机取其中一个，如 待支付,已支付,已取消。
  • 自定义模板：用 {{类型}} 占位符拼接任意字段，如 ORDER-{{date}}-{{int}}、{{username}}@{{domain}}。

支持的输出格式

  • JSON 数组：标准 [{...}, {...}] 结构，带缩进，完整保留嵌套层级，可直接粘进前端代码或接口 Mock。
  • CSV：按顶层键拆列，嵌套对象/数组序列化为 JSON 字符串写入单元格，可导入 Excel 或数据库。
  • JSON Lines：每行一个独立 JSON 对象，适合日志系统、流式处理与按行解析场景。

如何快速开始？

第一步：配置字段结构

页面默认载入嵌套示例；也可点"常用示例"回到扁平结构，用"＋ 常用字段"快选下拉或"＋ 新增字段"按钮逐行添加。

第二步：设置条数与参数

填写生成条数（1~1000），选择输出格式；按需配置随机整数范围、数组长度（默认 1~3）与日期范围——日期、时间、时间戳类字段在范围内随机，止不填默认为今天，起不填默认止往前一年。

第三步：生成并取用结果

修改任意行都会自动重新生成；点击"复制"取用文本，或"下载"得到 .json / .csv / .ndjson 文件。点"生成数据"可换一批。

典型应用场景

接口联调：生成字段齐全、嵌套层次真实的用户/订单 JSON，前端先跑起来，后端接口就绪后无缝替换。

组件演示：给表格、图表组件喂一批带姓名/日期/数值的演示数据（CSV 可直接粘进"数据转图表"工具）。

导入测试：导出 CSV 验证系统的批量导入、去重、字段校验逻辑；用枚举类型构造状态列验证分支。

压力占位：批量生成 UUID、IP、时间戳与多层数组，填充缓存或消息队列的测试报文。

特点与优势

本地生成，保护隐私 无需注册，即用即走 45+ 种字段类型 点号路径多层嵌套 数组长度可配置 自定义模板与枚举 日期范围可配置 导入 JSON 自动识结构 单次最多 1000 条 JSON / CSV / JSON Lines 一键复制与下载

注意事项：

  • 生成的数据均为随机虚构值，请勿当作真实用户数据使用，也不要用于伪造身份、虚假注册等违规用途。
  • 自增 ID 每次点击"生成数据"都从 1 重新开始；跨批次需要唯一主键时建议改用 UUID 类型。
  • 身份证、银行卡等证件号仅保证校验位算法合法，不对任何真实证件有效。
  • 同一路径先写成标量后又写成对象/数组时结构会冲突，生成后请检查输出结果。
  • 嵌套层数多且数组长度大时记录内容会成倍增长，建议控制数组长度上限。
  • 数据在浏览器本地生成，不上传服务器，仍建议在安全环境中操作。

常见问题

问：生成的手机号是真实号码吗？

答：不是。手机号从公开号段随机拼接 11 位数字，符合格式规律但不指向任何真实机主，仅供测试使用。

问：能让两次生成的数据一样吗？

答：工具不提供随机种子功能。需要稳定的数据集时，生成后立即下载保存，之后反复使用同一份文件。

问：CSV 打开后中文乱码怎么办？

答：下载的文件为 UTF-8 编码。用 Excel 直接双击打开旧版 CSV 可能识别错编码，建议通过"数据 → 从文本导入"并选择 UTF-8。

问：可以自定义字段名和字段内容吗？

答：可以。字段路径就是输出键名，任意命名、任意嵌套；类型选"枚举"可限定候选值，选"自定义模板"可用 {{name}}、{{date}} 等占位符拼接任意字段生成自定义格式的值。

问：如何生成对象数组（如订单列表）？

答：多行共用同一数组路径前缀即可，如 orders[].sku、orders[].amount、orders[].items[].name，这些字段会组合在同一个数组元素内，点"嵌套示例"按钮可一键载入该结构的模板。

问：可以导入已有的 JSON 结构吗？

答：可以。点"导入 JSON"粘贴接口响应样例（对象或对象数组），工具按键名与值特征自动推断类型生成结构表，嵌套/数组同样支持；不可识别的字符串字段会保留原值作为自定义模板，推断结果可在结构表中逐行调整。

问：数组长度是什么意思？

答：对以 [] 结尾的路径（如 tags[]、orders[]），工具条里的"数组长度"控制每条记录中该数组随机包含的元素个数（默认 1~3）。多个不同数组共用同一个长度区间；如需更复杂可逐次调整。

问：JSON、CSV、JSON Lines 怎么选？

答：前端联调、接口 Mock 用 JSON 数组（完整保留嵌套）；导入 Excel/数据库用 CSV（嵌套对象会序列化入单元格）；日志、流式处理、逐行解析场景用 JSON Lines。

生成示例：从结构表到输出

定义字段结构（路径 + 类型）

id 自增 ID name 中文姓名 profile.city 城市 profile.age 整数 tags[] 枚举：标签A,标签B,标签C orders[].sku 自定义模板：SKU-{{int}} orders[].items[].name 商品名称 orders[].items[].qty 整数

生成的单条记录（JSON）

{ "id": 1, "name": "张伟", "profile": { "city": "广州市", "age": 28 }, "tags": ["标签A", "标签C"], "orders": [ { "sku": "SKU-1042", "items": [ { "name": "智能手环", "qty": 2 }, { "name": "机械键盘", "qty": 1 } ] } ] }

要点解读

  • profile.city、profile.age 共用 profile. 前缀，合并为一个嵌套对象。
  • tags[] 为标量数组，元素个数在"数组长度"区间（1~3）内随机，取自枚举候选。
  • orders[].sku 与 orders[].items[] 共用 orders[] 前缀，同一元素内既有 sku 字段又有子数组。
  • orders[].items[].name、.qty 组成二层嵌套的对象数组，每个子项包含 name + qty。

使用最佳实践

  • 先小批后大批：先按 10 条确认结构与格式符合预期，再放大到 1000 条。
  • 从示例出发：点"常用示例 / 嵌套示例"载入模板，在示例基础上改路径和类型比从零配置更快。
  • UUID 代替自增 ID：多批次数据合并去重时，UUID 类型可保证主键不冲突。
  • 模板拼接业务键：用自定义模板生成符合业务规则的编号，如 ORDER-{{date}}-{{int}}。
  • 配合 CSV 工具箱：生成的 CSV 可在"CSV 工具箱"里继续做排序、去重、转格式。
  • 及时下载留存：每次点击都会重新随机，满意的结果请立即复制或下载。
