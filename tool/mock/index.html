工具介绍

造测试数据不必再手写

  • 联调接口、演示表格组件、验证导入功能时，总需要一批“看起来像真的”的数据。手写十几行费时，网上找的样例库又未必贴合字段。本工具按你定义的字段结构，一次生成最多 1000 条结构化记录。
  • 内置 45+ 种常用字段：中文/英文姓名、性别、手机号、邮箱、地址、身份证（带校验位）、银行卡（Luhn 合法）、公司、职业、经纬度、段落等，按基础/标识/地理/企业/时间/网络/文本分组快选。
  • 字段路径支持点号分层与 [] 数组（如 profile.city、orders[].items[].qty），任意键名可配自定义模板或枚举候选值；结果支持 JSON 数组、CSV、JSON Lines 三种格式，一键复制或下载成文件。

核心功能

  • 结构表式配置：每行一个字段（路径 + 类型 + 配置），可自由增删排序；嵌套对象用点号、数组用 [] 后缀，层级不限。
  • 手机号、身份证、银行卡、日期等均符合真实格式规律（随机号段、校验位、近年日期），但不指向任何真实个人。
  • 全部随机数由浏览器本地生成（Web Crypto / Math.random），不请求任何第三方接口。

使用说明

  1. 在字段结构表中定义每一行：字段路径（如 name、profile.city、tags[]、orders[].sku）与数据类型，可从“常用字段”快选下拉直接添加。
  2. 类型选“枚举”时在配置列填候选值（逗号分隔）；选“自定义模板”时用 {{name}}、{{date}} 等占位符拼接任意字段。
  3. 设置生成条数（1~1000）、输出格式、随机整数范围、数组长度与日期范围（日期/时间/时间戳在范围内随机，止缺省为今天），点击“生成数据”，随时可改结构自动重生成。
  4. 点击“复制”取用文本，或“下载”得到 .json / .csv / .ndjson 文件；“常用示例 / 嵌套示例”按钮可一键载入模板参考。
  5. “导入 JSON”按钮可粘贴接口响应样例（对象或对象数组），自动按键名与值特征推断类型生成结构表，嵌套与数组结构同样支持。

注意事项

  • 生成的数据均为随机虚构值，请勿当作真实用户数据使用；也不要将真实个人信息与本工具产物混用。
  • CSV 格式只按顶层键拆列，嵌套对象/数组会序列化为 JSON 字符串写入单元格；需要扁平结构时请用点号路径平铺字段。
  • 一次最多生成 1000 条；嵌套层数多且数组长度大时记录总数会成倍增长，建议控制数组长度上限。
  • 同一父级下的子字段共享一个对象；若同一路径先写成标量后又写成对象/数组，以结构能合并的为准，注意检查输出结果。

进阶技巧

  • 先小批后大批：先生成 10 条确认结构与格式符合预期，再放大到 1000 条批量造数据。
  • 跨批次主键：自增 ID 每次生成都从 1 重新开始；需要合并多批数据时，用 uuid 类型作主键避免冲突。
  • 嵌套订单结构：orders[].sku、orders[].amount、orders[].items[].name 多行共用同一路径前缀即可组合出对象数组，数组内字段在同一元素中取值一致。
  • 自定义拼接：用“自定义模板”类型把多个字段合并成一个值，如订单号 ORDER-{{date}}-{{int}}、头像 URL 拼接业务参数。
  • 工具组合：输出的 JSON 可直接粘进“JSON 工具箱”格式化/转结构，CSV 可继续用“CSV 工具箱”排序去重，或粘进“数据转图表”工具演示可视化效果。
