工具介绍

造测试数据不必再手写

  • 联调接口、演示表格组件、验证导入功能时，总需要一批"看起来像真的"的数据。手写十几行费时，网上找的样例库又未必贴合字段。本工具按你勾选的字段模板，一次生成最多 1000 条结构化记录。
  • 内置 16 种常用字段：中文/英文姓名、性别、手机号、邮箱、地址、日期、日期时间、时间戳、随机整数（范围可配）、随机小数、布尔值、UUID、IP 地址、颜色值，字段名即 JSON 键名，生成即可用。
  • 结果支持 JSON 数组、CSV、JSON Lines 三种格式，一键复制或下载成文件；生成的 CSV 还能直接粘进"数据转图表"工具演示可视化效果。

核心功能

  • 字段模板勾选式配置，支持全选/清空快捷操作；各字段以英文键名输出（id / name / phone / email …）。
  • 手机号、邮箱、日期等均符合真实格式规律（随机号段、随机域名、近年日期），但不指向任何真实个人。
  • 全部随机数由浏览器本地生成（Web Crypto / Math.random），不请求任何第三方接口。

使用说明

  1. 勾选需要的字段模板（默认已选 ID、姓名、性别、手机号、邮箱、随机整数）。
  2. 设置生成条数（1~1000）、输出格式，以及随机整数的取值范围。
  3. 点击"生成数据"，结果出现在右侧输出区，可重新点击换一批。
  4. 点击"复制"取用文本，或"下载"得到 .json / .csv / .ndjson 文件。

注意事项

  • 生成的数据均为随机虚构值，请勿当作真实用户数据使用；也不要将真实个人信息与本工具产物混用。
  • CSV 格式默认首行为英文字段名表头；文本含逗号时自动加引号转义。
  • 一次最多生成 1000 条，更大规模建议分批生成或下载文件后处理。

进阶技巧

  • 先小批后大批：先生成 10 条确认字段组合与格式符合预期，再放大到 1000 条批量造数据。
  • 跨批次主键：自增 ID 每次生成都从 1 重新开始；需要合并多批数据时，勾选 UUID 字段作主键避免冲突。
  • 固定数据集：随机值每次点击都会变化；需要可复现的数据时，生成后立即下载保存，后续反复用同一份文件。
  • 工具组合：输出的 CSV 可继续用“CSV 工具箱”排序/去重/转格式，或粘进“数据转图表”工具演示可视化效果。
  • 按场景选字段：用户表选 id+姓名+性别+手机号+邮箱+日期；订单流水选 uuid+日期时间+时间戳+随机小数；配置演示选整数+IP+颜色值。
