什么是行处理工具？

行处理工具是一款免费的在线多行文本整理助手。名单去重、标签排序、给列表加行号、给每行代码补引号逗号——这些以"行"为单位的零散需求，手写脚本麻烦、用编辑器又要点好几下，本工具一站式解决。

所有操作可组合执行，并按固定先后顺序进行：先去空行去空格、再去重、再排序或翻转、最后加行号与前后缀，结果清晰可预期。除粘贴文本外，也可直接上传 .xlsx / .csv / .txt / .tsv / .log 文件载入内容。全部逻辑在浏览器本地运行，不加载任何第三方处理库。

支持的处理

  • 清理：去除空行、去除每行首尾空格、按行去重（保留首次出现）。
  • 排序重排：字母升/降序、数字升/降序、按长度升/降序、翻转行序、随机打乱。
  • 改写：加行号（1. / 1 / 001 / 1)）、每行统一加前缀或后缀、全大写/全小写/首字母大写。
  • 统计：实时显示处理前后的行数、词数、字符数与去重/去空移除条数。
  • 文件导入：支持拖放/选择 .xlsx（本地解析取首个工作表）、.csv / .txt / .tsv / .log 直接载入文本。

如何快速开始？

第一步：粘贴文本

把多行文本粘贴到输入框，或点击"载入示例"体验。

第二步：组合选项

按需勾选去重、去空行、去空格、排序方式、翻转/打乱、加行号、前后缀与大小写。

第三步：处理并取用

点击"处理"生成结果并查看统计，复制或下载后粘回编辑器、文档或数据源。

典型应用场景

名单去重：重复填写的邮箱、手机号，去空行+去重一步清理干净。

代码片段：给每行 JSON 字段补引号逗号，或统一加前缀成数组元素。

清单编号：无序待办一键加上 1. 2. 3. 或 001 补零对齐行号。

排序整理：标签按字母排序、题目按序号重排、按长度筛最长行。

特点与优势

本地处理，保护隐私 多操作可组合 固定顺序、结果可预期 四种行号格式 前后缀批量 行/词/字符统计 支持上传 xlsx/csv/txt 一键复制与下载

注意事项：

  • 处理顺序固定：去空格 → 去空行 → 去重 → 大小写 → 排序/翻转/打乱 → 加行号 → 前后缀。
  • 去重区分大小写；要忽略大小写请先做"全小写"转换再去重。
  • 数字排序取每行第一个数字，无数字的行排末尾；随机打乱每次结果不同。
  • 数据在浏览器本地处理，不会上传服务器，公共设备建议配合无痕模式。

常见问题

问：同时勾了很多操作，先算哪个？

答：固定顺序去空格→去空行→去重→大小写→排序/翻转/打乱→加行号→前后缀，行号总是在最终排序后编号。

问：Apple 和 apple 会被当成重复吗？

答：不会，去重区分大小写。先做"全小写"转换再去重即可忽略大小写。

问：数字排序取的是哪个数？

答：取每行出现的第一个数字作为排序键，没有数字的行排在末尾。

问：字母升序是自然序吗？item2 和 item10 谁在前？

答：字母升/降序采用自然序比较，会识别字符串中的数字大小，因此 item2 排在 item10 前；比较时忽略大小写。若要严格按行内第一个数值排序，请用“数字升/降序”。

问：同时用了行号与前缀后缀，谁在外面？

答：固定顺序下行号先于前后缀，所以前后缀会包在行号外层。例如前缀 "、后缀 ", 行号 1.，得到 "1. apple",。若想行号在最外，分两次处理。

问：001 补零行号的宽度会多宽？

答：按总行数的位数对齐且至少 3 位（不足补零）：如 8 行时统一为 3 位 001，120 行时为 3 位，超过 999 行则按实际位数扩展。

问：会上传我的文本吗？

答：不会。全部处理在浏览器本地完成，可用 F12 的 Network 面板验证，关闭页面即清除。

处理示例：输入→输出

原始多行文本（含重复、空行、多余空格）

banana apple cherry apple date Elderberry fig banana

勾选：去首尾空格 + 去空行 + 去重 + 字母升序 + 行号（1.）

1. apple 2. banana 3. cherry 4. date 5. Elderberry 6. fig

统计条显示：结果 6 行（原文 9 行，去重/去空移除 3）。

前后缀拼接代码片段（把一列字符串变成数组元素）

输入两行 apple、fig，前缀填 "、后缀填 ",，得到：

"apple", "fig",

行号与前后缀同时开启时，因行号先于前后缀执行，前后缀会包在行号外层；需不同结果可分两次处理。

使用最佳实践

  • 先去空再排序：清理类操作放前面能避免空行干扰去重与排序结果，默认顺序已如此设计。
  • 大小写配合去重：需要忽略大小写去重时，先"全小写"再去重，效果最稳。
  • 前后缀生成代码：给一列字符串加 " 前缀与 ", 后缀，快速得到可粘贴进数组/IN 子句的片段。
  • 配合数据处理工具：清理好的一列值可继续送入"数据统计器""表格转 SQL INSERT"等工具。
  • 本地处理：文本全程在浏览器，关闭页面即清除。
