工具介绍

多行文本的批量整理利器

  • 一份名单要按行去重、一列名字要排序、抓下来的文本要加行号、给每行代码补上引号逗号——这些零散需求手写脚本麻烦、用编辑器又要点好几下，本工具一站式解决。
  • 所有操作以"行"为单位组合执行：先去空行去空格、再去重、再排序或翻转、最后加行号与前后缀，顺序合理、结果可预期。
  • 处理全在浏览器本地完成，文本不会上传到任何服务器，可用 F12 的 Network 面板验证。

核心功能

  • 清理与去重：去除空行、去除每行首尾空格、按行去重并保留首次出现顺序。
  • 排序与重排：字母升/降序、数字升/降序、按长度升/降序、翻转行序、随机打乱。
  • 批量改写：自动加行号（1.、1、001、1) 等格式）、每行统一加前缀/后缀、大小写与首字母大写转换，实时统计行数/词数/字符数。

使用说明

  1. 把多行文本粘贴到左侧输入框，或点击"载入示例"体验。
  2. 按需组合选项：去重、去空行、去空格、排序方式、翻转/打乱、加行号、前后缀、大小写。
  3. 点击"处理"，右侧生成结果，下方统计行数/词数/字符数（含处理前后对比）。
  4. 复制或下载处理后的文本，直接粘回编辑器、文档或数据源。

注意事项

  • 操作有固定先后顺序：去空格 → 去空行 → 去重 → 大小写 → 排序/翻转/打乱 → 加行号 → 前后缀；不同顺序会得到不同结果，可按需要分两次处理。
  • 去重按处理前的行内容精确匹配（区分大小写，除非先做了大小写转换）；数字排序取每行首个数字，无数字的行排在末尾。
  • 随机打乱每次结果不同且不保证稳定；超大文本（数十万行）建议分批处理，以免浏览器卡顿。

典型场景

  • 名单去重：把重复填写的邮箱、手机号名单粘贴进来，去空行+去重一步清理干净。
  • 代码片段：给每行 JSON 字段加上引号和逗号后缀，或给一堆字符串加前缀统一成数组元素。
  • 清单编号：把无序待办列表一键加上 1. 2. 3. 行号，或 001 补零对齐便于引用。
  • 排序整理：按字母给一堆标签排序、按数字给题目序号重排、按长度筛出最长/最短的几行。
  • 数据预处理：把一列值去重去空后，再送进 CSV 工具箱、数据统计器或表格转 SQL 工具继续处理。
