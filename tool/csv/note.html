什么是 CSV 工具箱？

CSV 工具箱是一款免费的在线表格数据处理助手。日常工作中经常需要在不同格式之间搬运表格数据：给前端接口用需要 JSON，写文档需要 Markdown 表格，做邮件周报需要 HTML 表格。手动改格式费时且容易改错，本工具一次解析、四种格式一键切换。

工具内置符合 RFC4180 的 CSV 状态机解析器，正确处理引号包裹、字段内逗号、双引号转义、字段内换行等边界情况；解析之后还提供去重、排序、转置、空行清理等常用表格操作。全部逻辑在浏览器本地运行，不加载任何第三方解析库。

支持的输入与输出

输入：逗号分隔的 .csv、Tab 分隔的 .tsv（可直接从 Excel 复制粘贴）、分号或竖线分隔的文本；分隔符支持自动识别。也可直接上传 .xlsx / .csv / .txt / .tsv 文件自动载入。

输出：

  • JSON：勾选"首行为表头"时输出对象数组（每行一个对象，键取自表头），否则输出二维数组；纯数字内容自动转为数值类型。
  • CSV：按当前分隔符重新规范化输出，自动处理引号转义。
  • Markdown：GitHub 风格表格，字段内的竖线与换行自动转义。
  • HTML：<table> 代码文本，表头行输出为 <th>，内容已做 HTML 转义，复制即用。

如何快速开始？

第一步：粘贴数据

把 CSV 文本粘贴到输入框，或从 Excel 直接复制单元格粘贴（Tab 分隔自动识别）；也可上传 .xlsx / .csv / .txt 文件，或点击“载入示例”体验。

第二步：设置处理选项

选择分隔符、是否含表头，按需勾选去空格、去空行、去重、转置，或填写排序列号（从 0 开始）与升/降序。

第三步：转换并取用结果

点击"转换"，右侧统计显示 行×列；切换标签页查看不同格式，点击"复制"或"下载"取用结果。

典型应用场景

前端开发：把接口Mock表格转成 JSON 数组直接塞进代码。

技术写作：把数据表转 Markdown 表格贴进 README 或博客。

办公协作：Excel 片段转 HTML 表格粘进邮件，格式不丢。

数据清洗：快速去重、去空行、按列排序后再导入系统。

特点与优势

本地处理，保护隐私 无需注册，即用即走 RFC4180 状态机解析 四种输出格式 分隔符自动识别 去重 / 排序 / 转置 支持上传 xlsx/csv/txt 一键复制与下载

注意事项：

  • 排序列号从 0 开始计数；表头行固定在最上方，不参与排序与去重。
  • 带单位或千分位的数字（如 12kg、1,200）按文本排序。
  • 若字段本身未加引号却包含分隔符，解析会列错位，请先修正源数据。
  • 超大文件（数万行以上）建议先在表格软件中拆分再处理。
  • 数据在浏览器本地处理，不会上传服务器，仍建议在安全环境中操作。

常见问题

问：字段包含逗号会被切错列怎么办？

答：标准 CSV 会用双引号包裹这类字段（字段内双引号写成两个连续双引号）。本工具的状态机解析器能正确处理引号内的逗号与换行；若源数据没按规范加引号，建议改用 Tab/分号分隔导出。

问：能从 Excel 直接粘贴吗？

答：可以。Excel 复制后粘贴到输入框的内容是 Tab 分隔文本，"自动识别"会选中 Tab 分隔符，无需先另存为 CSV。

问：JSON 结果里的数字为什么还是字符串？

答：内容能被完整解析为数字（如 28、92.5）时会自动转为数值类型；带单位、空格或千分位逗号的会保留为字符串。

问：HTML 输出会执行脚本吗？

答：不会。输出的 HTML 是转义后的代码文本（< 等已转义显示），仅供复制使用，工具不会将其注入页面执行。

问：支持直接上传文件吗？

答：支持。除粘贴文本外，可上传 .xlsx（浏览器本地解析取首个工作表）、.csv / .txt / .tsv 自动载入并转换，全程本地完成不上传。

问：开启“转置”后表头会怎样？

答：转置会把整个表格（含表头行）做行列互换，原来的第一列变成第一行；因为是对解析后的整块操作，表头行不会被单独剔除，若只想转数据部分可先不开表头处理。

转换示例：一份数据→四种格式

输入 CSV（勾选“首行为表头”）

name,city,age,score Alice,Beijing,28,92.5 Bob,Shanghai,35,78

输出 JSON（纯数字自动转为数值）

[ { "name": "Alice", "city": "Beijing", "age": 28, "score": 92.5 }, { "name": "Bob", "city": "Shanghai", "age": 35, "score": 78 } ]

输出 Markdown 表格

| name | city | age | score | | --- | --- | --- | --- | | Alice | Beijing | 28 | 92.5 | | Bob | Shanghai | 35 | 78 |

输出 HTML 表格

<table> <tr><th>name</th><th>city</th><th>age</th><th>score</th></tr> <tr><td>Alice</td><td>Beijing</td><td>28</td><td>92.5</td></tr> <tr><td>Bob</td><td>Shanghai</td><td>35</td><td>78</td></tr> </table>

同一份解析结果可在标签页之间自由切换，无需反复粘贴；若源数据末尾有重复行，勾选“去重”会删除与前面完全相同的数据行（表头行除外）。

使用最佳实践

  • 先转换再切格式：选项处理后，切换标签页不会重复解析，可放心对比各格式。
  • 善用示例：第一次使用先点"载入示例"，观察各选项对结果的影响。
  • 检查行列统计：转换后留意"行×列"统计，列数与预期不符说明分隔符或引号有问题。
  • 配合图表工具：清洗好的 CSV 可直接粘贴到"数据转图表"工具生成图表。
  • 本地处理：数据全程在浏览器本地，关闭页面即清除，公共设备建议配合无痕模式。
