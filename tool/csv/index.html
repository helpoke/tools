工具介绍

表格数据一键换格式

  • 从 Excel 或数据库导出的 CSV，交给前端框架却需要 JSON；写文档要 Markdown 表格；邮件里又想要 HTML——同一份数据反复手改格式既费时又容易改错。本工具把任意 CSV/TSV 一次解析，四种格式一键切换。
  • 内置完整的 CSV 状态机解析器，正确处理引号包裹、字段内逗号、双引号转义、字段内换行等边界情况，不再为“最后一列多一个逗号”导致的列错位烦恼。
  • 去重、排序、转置、清理空行等常用操作在浏览器本地完成，您的业务数据不会上传到任何服务器，可用 F12 的 Network 面板验证。

核心功能

  • 多格式输出：JSON（对象数组/二维数组）、CSV（可换分隔符重新组合）、Markdown 表格、HTML 表格，点标签页即时切换。
  • 分隔符自动识别：逗号、分号、Tab、竖线四种常见分隔符按频率自动选择，也可手动指定。
  • 表格处理：表头识别、按列升/降序排序（数字智能比较）、去除重复行、移除空行、行列转置、首尾空格清理。

使用说明

  1. 把 CSV/TSV 文本粘贴到左侧输入框（可直接从 Excel 复制 Tab 分隔的内容），或点击“载入示例”体验。
  2. 选择分隔符（默认自动识别）与处理选项：表头、去空格、去空行、去重、转置、排序列号（从 0 开始）。
  3. 点击“转换”，在右侧切换 JSON / CSV / Markdown / HTML 标签页查看不同格式的结果。
  4. 复制结果或直接下载对应格式文件，粘进代码、文档或网页即可使用。

注意事项

  • 排序列号从 0 开始计数；勾选“首行为表头”时，表头行固定在第一行不参与排序与去重。
  • 数字列智能排序：纯数字内容按数值比较，其他按文本自然序比较；带单位的字符串（如 “12kg”）会被视为文本。
  • 所有处理均在本地浏览器完成，关闭页面即清除数据；超大文件（数万行以上）建议先用表格软件拆分后再处理。

典型场景

  • 前端联调：把接口字段表格转成 JSON 对象数组直接写进代码，纯数字自动转数值类型，省去逐个手改引号。
  • 技术写作：数据表一键转 Markdown 表格贴进 README、博客或 Wiki，对齐竖线与分隔行自动生成，不用手工排版。
  • 邮件周报：从 Excel 复制单元格直接粘贴（Tab 分隔自动识别），转 HTML 表格粘进邮件正文，表格样式不丢。
  • 数据清洗：先去除重复行、空行并按关键列排序，再导出 CSV/JSON 导入目标系统，避免脏数据进库。
  • 报表演示：把清洗好的表格粘进“数据转图表”工具，表格数据秒变柱状图/折线图，汇报材料一步到位。
