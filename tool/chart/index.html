工具介绍

让数据一眼看懂

  • 表格里的数字很难一眼看出趋势和占比。本工具把结构化的 JSON 或 CSV 数据，一键渲染成直观的图表——柱状图对比大小、折线图看趋势、饼图看占比、散点图看分布。无需安装 Excel、无需连接任何图表服务器，粘贴数据即可出图。
  • 工具内置 6 种常用图表类型（柱状图、折线图、面积图、饼图、环形图、散点图），支持多数据集对比、坐标轴标题、图例、网格线和自适应刻度。渲染基于原生 Canvas 2D 绘制，不依赖任何第三方图表库，加载更快、体积更小。
  • 所有解析和绘制都在浏览器本地完成——你的经营数据、统计报表不会上传到任何服务器，可用 F12 的 Network 面板验证。生成的图表可一键导出为高清 PNG 图片，直接插入 PPT、Word、网页或邮件。

核心功能

  • 规范数据结构：工具定义了一套简洁的 JSON 数据规范（type / title / labels / datasets），并提供模板下载。你也可以直接粘贴常见的 CSV 表格（首列为分类标签，其余列为数据系列），系统自动识别。
  • 实时预览：编辑数据后自动重新渲染，切换上方图表类型按钮即可在同一份数据上换一种展示方式。
  • 主题配色：内置多彩、海洋、暖色、森林、单色 5 套配色方案，一键切换图表整体风格。
  • 下载导出：点击"下载"导出高清 PNG 图片；点击全屏按钮可放大查看大型数据集。

使用说明

数据结构规范

  • type：图表类型，可选 bar、line、area、pie、doughnut、scatter（也可点击页面上方按钮切换）。
  • title / xTitle / yTitle：图表标题与 X、Y 轴标题，可省略。
  • labels：横轴/分类标签数组，如 ["一月","二月","三月"]。饼图、环形图中它表示每个扇区的名称。
  • datasets：数据系列数组，每个系列包含 name（名称）、color（可选，#RRGGBB）、data（与 labels 等长的数值数组）。饼图/环形图通常只有一个系列。
  • CSV 兼容：直接粘贴 名称,系列A,系列B 这样的表格文本，首行会被当作系列名，首列被当作 labels。散点图的 labels 会被视为数值 X 坐标。

基本使用方法

  • 载入示例：点击"示例数据"下的按钮，即可载入一份完整示例，快速体验各类图表。
  • 下载模板：点击"下载模板"获取标准 JSON 结构文件，用编辑器打开替换成你的数据。
  • 上传数据：点击"上传"选择本地 .json 或 .csv 文件载入。
  • 编辑数据：在左侧文本框修改数据，右侧图表实时刷新。

图表交互功能

  • 切换类型：点击上方图表类型按钮，用同一份数据切换展示方式。
  • 主题配色：点击预览区上方的颜色圆点切换配色方案。
  • 下载图片：点击"下载"按钮导出高清 PNG 图表。
  • 全屏预览：点击全屏按钮放大查看图表，再次点击或按 Esc 退出。
  • 格式化：点击"格式化"按钮把 JSON 数据整理为缩进友好的排版。

注意事项

数据要点

  • 每个系列的 data 数组长度应与 labels 一致；若某个点缺失数据，可用 null 占位，折线图会自动断开，柱状图会跳过该柱。
  • 数值需为数字类型（不要带单位或千分位字符串）。若需要显示单位，请写在 yTitle 中，例如 "销售额(万元)"。
  • 饼图和环形图用于展示"部分与整体"的占比，建议分类数量控制在 8 个以内，过多分类会让扇区难以辨认。

排错建议

  • 提示"数据解析失败"？检查 JSON 是否用了中文引号、是否多了尾逗号、括号是否闭合。可先点击"格式化"验证 JSON 是否合法。
  • 图表空白？确认 datasets 至少有一个系列且 data 非空；饼图/环形图不要使用多个系列。
  • 下载的 PNG 模糊？本工具按设备像素比渲染，Retina 屏幕下已较为清晰。如需超高清图用于印刷，建议全屏放大后再截图。

隐私保护

  • 你的经营数据、统计报表的解析与绘制完全在浏览器本地完成，不会通过网络传输到任何服务器。本工具不使用 localStorage 持久化数据，关闭标签页后即从内存中清除。
  • 在公共设备上使用时，建议配合浏览器无痕模式，关闭后不保留任何缓存与记录。
