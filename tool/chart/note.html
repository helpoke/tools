什么是数据转图表工具？

数据转图表工具是一款免费的在线数据可视化助手。表格里的数字往往难以一眼看出趋势、对比和占比，本工具把结构化的 JSON 或 CSV 数据即时渲染成直观的图表——柱状图对比大小、折线图看趋势、面积图看累积、饼图/环形图看占比、散点图看分布。

与依赖重量级图表库或需要连接图表服务器的方案不同，本工具使用浏览器原生 Canvas 2D 自行绘制，不加载任何第三方图表脚本，打开即用、速度快；所有的数据解析和图像生成都在您本地浏览器完成，敏感的经营数据、统计报表绝不会上传。

规范的数据结构

推荐使用如下 JSON 结构（可点击工具页的"下载模板"按钮获取文件）：

{ "type": "bar", "title": "季度销售额对比", "xTitle": "季度", "yTitle": "销售额 (万元)", "labels": ["Q1", "Q2", "Q3", "Q4"], "datasets": [ { "name": "线上渠道", "color": "#5470c6", "data": [320, 410, 380, 520] }, { "name": "线下门店", "color": "#91cc75", "data": [220, 260, 300, 340] } ] }

  • type：图表类型，可选 bar、line、area、pie、doughnut、scatter。
  • title / xTitle / yTitle：图表与坐标轴标题，均可省略。
  • labels：分类标签数组；散点图中它会被当作数值 X 坐标。
  • datasets：数据系列数组，每项含 name、color（可省略）、data（与 labels 等长的数值数组，缺失点用 null）。

如何快速开始？

第一步：载入数据

点击"示例数据"下的按钮载入完整示例；或点击"下载模板"获取标准结构文件，用编辑器替换成你的数据后粘贴；也可以"上传"本地 .json / .csv 文件。

第二步：选择图表类型

点击上方类型按钮，用同一份数据切换展示方式。饼图/环形图建议使用单系列数据。

第三步：调整配色与导出

点击预览区上方的颜色圆点切换 5 套配色（多彩、海洋、暖色、森林、单色）。满意后点击"下载"导出高清 PNG，或点击全屏按钮放大查看。

注意事项：

  • 数值必须为纯数字，不要包含单位或千分位逗号，单位请写在 yTitle 中。
  • 每个系列的 data 长度应与 labels 一致，缺失点用 null 占位。
  • 饼图 / 环形图用于"部分与整体"，分类建议不超过 8 个。
  • JSON 不要使用中文引号或尾逗号，否则解析失败。
  • 数据在浏览器本地处理，不会上传服务器，仍建议在安全环境中操作。

常见问题

问：提示"数据解析失败"怎么办？

答：多为 JSON 语法问题：中文引号、多余尾逗号、括号未闭合，或数值写成了字符串。先点"格式化"验证 JSON 是否合法，或"下载模板"以标准结构为底修改。

问：能用 CSV 表格吗？

答：可以。直接粘贴形如 名称,系列A,系列B 的表格文本，首行作为系列名，首列作为分类标签，系统自动识别为柱状图，之后可再切换类型。

问：导出的图片模糊吗？

答：导出按 2 倍分辨率渲染，Retina 屏清晰锐利。预览与导出均跟随浏览器明暗主题，所见即所得。

问：可以画多系列对比吗？

答：可以。在 datasets 中放多个系列即可，柱状图会分组并排、折线/面积图会叠加显示，并自动生成图例。

使用最佳实践

  • 先套模板：不确定结构时，点击"下载模板"以规范 JSON 为底修改，避免语法错误。
  • 善用示例：点击"示例数据"按钮查看各类图表的完整数据写法。
  • 检查敏感信息：分享导出的图片前，确认其中不含需要保密的数据。
  • 验证输出：导出 PNG 后在目标场景（PPT/网页）中确认清晰度与配色。
  • 本地处理：数据全程在浏览器本地，关闭页面即清除，公共设备建议配合无痕模式。
