工具介绍

一、解决的问题

  • 进制转换是编程和计算机操作中常见的需求，但手动进行进制转换容易出错且效率低下。
  • 不同进制的数字表示方式差异较大，开发者需要频繁在二进制、八进制、十进制、十六进制之间切换。
  • 对于非专业人士来说，理解和转换不同进制的数字是一项挑战。

二、支持的格式

  • 二进制(BIN)：仅包含数字 0 和 1，支持前缀 0b。
  • 八进制(OCT)：包含数字 0-7，支持前缀 0o。
  • 十进制(DEC)：包含数字 0-9，日常最常用的进制。
  • 十六进制(HEX)：包含数字 0-9 和字母 A-F（大小写均可），支持前缀 0x。

三、核心功能

  • 实时转换：输入数字后立即显示所有进制的转换结果，无需手动触发。
  • 一键复制：支持单独复制某个进制的结果，或一次性复制全部结果。
  • 预设值：提供常用数值的快速输入，方便测试和学习。
  • 自动识别：智能识别进制前缀，自动切换到对应的进制输入模式。

使用说明

一、进制转换功能

  • 选择源进制：点击上方的进制标签（BIN/OCT/DEC/HEX）选择输入数字的进制类型。
  • 输入数字：在输入框中输入需要转换的数字，系统会自动进行实时转换。
  • 查看结果：转换结果会同时显示为二进制、八进制、十进制、十六进制四种格式。
  • 复制结果：点击每个结果右侧的"复制"按钮可以单独复制该进制的数值，或点击"复制全部"一次性复制所有结果。
  • 使用预设：点击下方的预设标签（如255、1024、0xFF等）可以快速填入常用数值进行转换。

二、进制格式说明

  • 二进制(BIN)：仅包含数字 0 和 1，如 101010。
  • 八进制(OCT)：包含数字 0-7，如 777。
  • 十进制(DEC)：包含数字 0-9，如 255。
  • 十六进制(HEX)：包含数字 0-9 和字母 A-F（大小写均可），如 FF。

三、快捷操作

  • 支持自动识别常见前缀：0b（二进制）、0o（八进制）、0x（十六进制）。
  • 按 Enter 键可触发转换。
  • 切换进制时，当前输入值会自动转换为新进制表示。

注意事项

一、格式规范

  • 输入的数字必须符合所选进制的格式要求，否则会提示错误。
  • 二进制仅允许 0 和 1，八进制仅允许 0-7，十进制仅允许 0-9，十六进制允许 0-9 和 A-F。
  • 数字不能包含空格、逗号或其他分隔符。

二、数值范围

  • 支持的数值范围为 -2^53 ~ 2^53（JavaScript 的安全整数范围）。
  • 超出安全范围的超大数字可能会丢失精度。
  • 负数转换时，十六进制结果会显示为负号加绝对值的十六进制表示。

三、数据安全

  • 所有转换均在本地浏览器完成，数据不会上传到服务器。
  • 建议不要在公共设备上处理包含敏感信息的数值。

四、常见问题

  • 转换报错：检查输入是否符合所选进制的格式要求。
  • 数值异常：超大数字可能超出 JavaScript 的安全整数范围，建议分段处理。
  • 复制失败：检查浏览器是否允许剪贴板访问。
