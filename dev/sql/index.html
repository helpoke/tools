SQL 格式化：让数据库查询语句清晰可读

                        

                        

                            
一、为什么 SQL 需要格式化

                            
    
                                
  • SELECT a.id, a.name, b.order_id, b.total FROM users a
                                    INNER JOIN orders b ON a.id = b.user_id WHERE b.total > 100 AND a.status = 'active'
                                    ORDER BY b.total DESC ——这段 SQL 功能正确，但挤在一行中很难快速理解查询逻辑。SQL
                                    格式化自动添加缩进、换行和关键字大写，将查询语句还原为结构化的可读格式。
    • 
                                
  • 本工具支持 SQL 的格式化和压缩两种模式。格式化将 SQL
                                    语句按标准风格排版——关键字大写、子句换行、条件缩进。压缩去除所有多余空白，生成紧凑的单行 SQL。
    • 
                                
  • 支持 MySQL、PostgreSQL、SQL Server、Oracle、SQLite 等主流数据库的
                                    SQL 语法。提供多种格式化风格——标准风格（关键字大写、每子句一行）、紧凑风格（减少空行）、自定义缩进（2 空格或 4 空格）。
    • 
                            

                            
二、支持的 SQL 方言

                            
    
                                
  • 标准 SQL：ANSI SQL
                                    标准语法——SELECT、INSERT、UPDATE、DELETE、CREATE TABLE、ALTER TABLE 等。所有数据库通用的基础语法。
    • 
                                
  • MySQL：支持 MySQL
                                    特有语法——反引号引用（`table_name`）、LIMIT 分页、GROUP_CONCAT、IFNULL 等。
    • 
                                
  • PostgreSQL：支持 PG
                                    特有语法——双引号引用（"table_name"）、RETURNING 子句、LATERAL JOIN、JSON 操作符（->>）等。
    • 
                            

                            
三、核心功能

                            
    
                                
  • 智能格式化：自动识别 SQL
                                    关键字和子句结构——SELECT、FROM、WHERE、JOIN、GROUP BY、HAVING、ORDER BY 等每个子句独占一行，条件表达式按层级缩进。
    • 
                                
  • 压缩模式：去除所有多余空白——将格式化的 SQL
                                    压缩为单行。适合嵌入代码或日志中。
    • 
                                
  • 统计信息：实时显示行数、字符数、关键字数——帮助你了解 SQL
                                    语句的复杂度。
    • 
                                
  • 纯前端处理：所有格式化在浏览器中完成——SQL
                                    语句不上传到服务器。
    • 
                            

                        

                    


                    

                        

                            
SQL 格式化操作指南

                        

                        

                            
格式化步骤

                            
    
                                
  • 粘贴 SQL：将 SQL
                                    语句粘贴到输入框——支持多语句（用分号分隔）。
    • 
                                
  • 压缩：点击"压缩"按钮去除多余空白——输出紧凑的单行 SQL。
                                
    • 
                                
  • 复制结果：点击"复制"按钮将格式化结果复制到剪贴板。
    • 
                                
  • 示例加载：点击"示例"按钮加载复杂 SQL
                                    示例——快速体验格式化效果。
    • 
                                
  • 清空：点击"清空"按钮清除输入和输出。
    • 
                            

                            
格式化选项

                            
    
                                
  • 
                                    格式风格：标准风格（关键字大写、每子句一行）或紧凑风格（减少空行）。
                                
    • 
                                
  • 缩进大小：2 空格（紧凑）或 4 空格（清晰）。
    • 
                                
  • 关键字大小写：大写（SELECT）、小写（select）或保持原样。
                                
    • 
                                
  • 子句间距：子句之间的空行数——0 行（紧凑）到 2
                                    行（宽松）。
    • 
                            

                            
五、SQL 语法速查

                            
    
                                
  • 查询：SELECT 列名 FROM 表名 WHERE 条件
                                    ORDER BY 排序 GROUP BY 分组 HAVING 过滤。
    • 
                                
  • 数据操作：INSERT INTO（插入）、UPDATE
                                    SET（更新）、DELETE FROM（删除）——操作数据库中的数据。
    • 
                                
  • 结构定义：CREATE TABLE（建表）、ALTER
                                    TABLE（修改表）、DROP TABLE（删除表）——定义数据库结构。
    • 
                                
  • 子句顺序：SELECT → FROM → WHERE → GROUP
                                    BY → HAVING → ORDER BY → LIMIT。SQL 的执行顺序与此书写顺序不同——FROM 先执行，SELECT 最后执行。
    • 
                                
  • 
                                    条件表达式：AND、OR、NOT、IN、BETWEEN、LIKE、IS NULL——组合使用构建复杂的筛选条件。
                                
    • 
                                
  • 流程控制：CASE WHEN THEN ELSE END——SQL
                                    中的条件表达式。支持在 SELECT、WHERE、ORDER BY 中使用。
    • 
                                
  • 
                                    聚合函数：COUNT()、SUM()、AVG()、MAX()、MIN()——配合 GROUP BY 使用，对分组数据进行统计计算。
                                
    • 
                            

                            
六、注意事项

                            
    
                                
  • 分号结尾：每条 SQL
                                    语句应以分号结尾——多语句时尤其重要。格式化工具会自动处理缺失的分号。
    • 
                                
  • 
                                    引号使用：字符串用单引号（'value'），标识符用反引号（MySQL）或双引号（PG/Oracle）。不要在 WHERE
                                    条件中漏写引号——数字类型不需要引号，字符串类型必须加。
                                
    • 
                            

                        

                    

                    

                        

                            
注意事项

                        

                        

                            
格式化注意

                            
    
                                
  • 多语句：多条 SQL
                                    用分号分隔——格式化工具对每条语句独立格式化。
    • 
                                
  • 字符串内容：SQL
                                    字符串中的单引号需要用两个单引号转义——'it''s' 表示 it's。格式化不会修改字符串内容。
    • 
                                
  • 注释保留：SQL 注释（-- 单行、/* */
                                    多行）在格式化时保留——不丢失注释内容。
    • 
                                
  • 反引号：MySQL
                                    用反引号引用标识符（`table`）——格式化工具保留反引号不修改。
    • 
                            

                            
关键字处理

                            
    
                                
  • 大写模式：所有 SQL
                                    关键字转为大写——SELECT、FROM、WHERE。这是最常见的 SQL 编码规范。
    • 
                                
  • 
                                    小写模式：所有关键字转为小写——select、from、where。部分团队偏好此风格。
                                
    • 
                                
  • 保持原样：不改变关键字的大小写——保留你原始的书写风格。
    • 
                                
  • 函数名：函数名（COUNT、SUM
                                    等）通常与关键字使用相同的大小写规则。
    • 
                            

                            
性能说明

                            
    
                                
  • 大文件：超过 1000 行的 SQL 文件格式化可能较慢——建议分段处理。
                                
    • 
                                
  • 存储过程：复杂的存储过程（含大量
                                    IF/LOOP/CURSOR）格式化效果可能不完美——建议手动微调。
    • 
                            

                            
数据安全

                            
    
                                
  • 纯前端处理：所有 SQL 格式化在浏览器中完成——SQL
                                    语句不上传到服务器。
    • 
                                
  • 敏感数据：虽然不上传数据，但如果 SQL
                                    中包含敏感信息（如密码、密钥），使用完毕后请清空输入。
    • 
                            

                            
常见问题

                            
    
                                
  • Q: 格式化失败？A: 检查 SQL
                                    语法是否正确——未闭合的引号、缺失的括号会导致解析失败。
    • 
                                
  • Q: 关键字没有转为大写？A:
                                    检查"关键字大小写"选项——需要选择"大写"模式。
    • 
                                
  • Q: 复制失败？A:
                                    部分浏览器需要授权剪贴板权限——可以手动选中输出内容复制。
