工具介绍

一、解决的问题

  • 格式化SQL语句，提高可读性和维护性。
  • 简化繁琐的手动操作，提高工作效率和准确性。
  • 无需安装专业软件，随时随地在线使用。

二、支持的格式

  • SQL：支持该格式的完整处理功能。
  • MySQL：支持该格式的完整处理功能。
  • PostgreSQL：支持该格式的完整处理功能。

三、核心功能

  • 在线处理：所有操作均在浏览器中完成，无需下载或安装。
  • 实时预览：处理结果即时显示，方便调整和确认。
  • 一键导出：支持快速导出处理后的文件或复制结果。
  • 数据安全：所有数据仅在本地处理，不会上传到服务器。

使用说明

一、格式化功能

  • 格式化：将压缩或杂乱的SQL代码转换为结构清晰、缩进正确的格式，便于阅读和维护。
  • 压缩：将格式化的SQL代码压缩为紧凑格式，去除多余空白，减小文件体积。
  • 复制结果：一键复制格式化或压缩后的代码到剪贴板。
  • 示例SQL：点击"示例SQL"按钮可以查看格式化效果的示例代码。
  • 清空：快速清除所有输入和输出内容。

二、格式化选项

  • 缩进：可选择2空格、4空格或Tab作为缩进单位，默认为4空格。
  • 关键字：可选择大写、小写或保持原样，默认为保持原样。
  • 语句间空行：设置每个SQL语句之间的空行数量，默认为1行。
  • AND/OR 换行：勾选后，AND/OR 关键字会单独换行显示。

三、支持的 SQL 语法

  • 数据查询：SELECT、FROM、WHERE、JOIN（INNER/LEFT/RIGHT/FULL/CROSS）
  • 数据操作：INSERT、UPDATE、DELETE、VALUES、SET
  • 数据定义：CREATE、ALTER、DROP、TABLE、INDEX、VIEW、DATABASE
  • 查询子句：ORDER BY、GROUP BY、HAVING、LIMIT、OFFSET
  • 条件表达式：AND、OR、NOT、IN、LIKE、BETWEEN、IS NULL
  • 流程控制：CASE、WHEN、THEN、ELSE、END
  • 聚合函数：COUNT、SUM、AVG、MIN、MAX

四、快捷操作

  • 输入和输出区域都支持独立复制操作。
  • 状态栏会实时显示行数、字符数和关键词数量。

注意事项

一、格式规范

  • SQL语句必须以分号 ; 结尾。
  • 字符串必须用单引号或双引号包裹。
  • 注释支持 --（单行）和 /* ... */（多行）。
  • 标识符（表名、列名）可以用反引号 ` 包裹。

二、关键字处理

  • 选择"大写"选项时，所有SQL关键字都会转换为大写。
  • 选择"小写"选项时，所有SQL关键字都会转换为小写。
  • 选择"保持原样"选项时，关键字保持原始大小写。
  • 函数名默认转换为大写。

三、性能提示

  • 处理超大SQL文件（超过1MB）时可能会导致浏览器卡顿。
  • 建议将大型SQL文件分段处理。

四、数据安全

  • 所有处理均在本地浏览器完成，数据不会上传到服务器。
  • 建议不要在公共设备上处理包含敏感信息的SQL代码。

五、常见问题

  • 格式化失败：检查SQL语法是否正确，特别是括号和引号是否匹配。
  • 关键字未转换：确保选择了正确的关键字大小写选项。
  • 复制失败：检查浏览器是否允许剪贴板访问。
