工具介绍

一、解决的问题

  • 快速进行文件大小单位换算，如 KB 转 MB、GB 转 TB 等。
  • 区分 SI（1000 进制）和 IEC（1024 进制）两种标准，避免混淆。
  • 实时显示所有单位的转换结果，无需反复计算。

二、支持的单位

  • Byte (B)：字节，最小存储单位，1 个英文字符 = 1 Byte。
  • Kilobyte (KB)：千字节，常见于小文件大小。
  • Megabyte (MB)：兆字节，常见于图片、音乐文件。
  • Gigabyte (GB)：吉字节，常见于视频、系统镜像。
  • Terabyte (TB)：太字节，常见于硬盘容量。
  • Petabyte (PB)：拍字节，数据中心级别。
  • Exabyte (EB)：艾字节，超大规模存储。

三、核心功能

  • 实时转换：输入数值即刻显示所有单位的转换结果，无需点击按钮。
  • 双标准支持：IEC（1024 进制，操作系统使用）和 SI（1000 进制，硬盘厂商使用）一键切换。
  • 一键复制：点击复制按钮快速复制任意转换结果。
  • 数据安全：所有计算在本地浏览器完成，不上传任何数据。

使用说明

一、选择换算标准

  • IEC 标准（1024 进制）：1 KB = 1024 B，Windows 操作系统、内存容量等使用此标准。
  • SI 标准（1000 进制）：1 KB = 1000 B，硬盘/U盘厂商标注容量、网络带宽等使用此标准。

二、输入数值和单位

  • 输入数值：在输入框中键入需要转换的文件大小数值。
  • 选择单位：从下拉菜单中选择输入数值的单位（如 MB）。
  • 快捷预设：点击预设按钮可快速填入常见文件大小。

三、查看转换结果

  • 全部结果：表格会同时显示该文件大小在所有单位下的值。
  • 复制结果：点击每行末尾的复制按钮可快速复制该值。

注意事项

一、为什么硬盘标称容量比系统显示的小？

硬盘厂商使用 SI 标准（1000 进制），而操作系统使用 IEC 标准（1024 进制）。例如 500GB 硬盘：厂商按 500×1000³ 计算，系统按 ÷1024³ 显示为约 465 GiB。这不是质量问题，而是标准差异。

二、精度说明

转换结果保留最多 6 位有效数字，极小或极大数值可能因浮点精度限制存在微小偏差。

三、IEC 与 SI 命名对照

  • IEC：KiB、MiB、GiB、TiB（1024 进制）
  • SI：KB、MB、GB、TB（1000 进制）
