正则表达式：文本处理的瑞士军刀

一、正则表达式为什么让人又爱又恨

  • \b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z]{2,}\b ——这串"天书"匹配的是邮箱地址。正则表达式（Regular Expression）是文本搜索和替换的终极工具——几乎所有编程语言、文本编辑器、命令行工具都支持它。但正则的语法极其晦涩，一个括号漏写就可能导致整个匹配失败。
  • 本工具提供可视化的正则表达式测试环境——输入正则表达式和测试文本，工具实时高亮所有匹配结果，显示匹配位置、捕获组内容和匹配统计。支持 JavaScript 和 Python 两种正则语法。
  • 内置 12 个常用正则预设——邮箱、手机号、URL、IP 地址、身份证号、中文字符等——一键加载，不需要从零编写。还提供正则语法速查表——字符类、量词、锚点、分组、断言——方便随时查阅。

二、正则表达式语法

  • 通用语法：正则表达式由字面字符和元字符组成。^ 匹配开头，$ 匹配结尾，. 匹配任意字符，* 匹配 0 次或多次，+ 匹配 1 次或多次，? 匹配 0 次或 1 次，[] 匹配字符集，() 分组捕获，| 表示或。
  • JavaScript 语法：支持 /pattern/flags 字面量语法。常用标志：g（全局匹配）、i（忽略大小写）、m（多行模式）。支持命名捕获组 (?...) 和前后瞻 (?=...) / (?!...)。
  • Python 风格参考：虽然浏览器环境使用 JavaScript 正则引擎，但本工具的语法速查表同时标注了 Python re 模块的等价语法。大部分基础语法（字符类、量词、分组）在两种风格中通用，少数高级特性（如命名分组语法）有差异。

三、核心功能

  • 实时匹配：输入正则表达式后，匹配结果立即在测试文本中高亮显示——不需要点击"测试"按钮。修改正则或测试文本都会实时更新。
  • 匹配详情：每个匹配结果显示起始位置、结束位置和匹配内容。捕获组单独列出——方便提取子匹配。
  • 搜索替换：输入正则表达式和替换文本，工具执行全局替换并显示替换后结果——支持 $1、$2 等反向引用。
  • 纯前端处理：所有正则匹配在浏览器中完成——测试文本不上传到服务器。

语法速查

  • 字符类：\d（数字）、\w（字母数字下划线）、\s（空白）、.（任意字符）。反义：\D、\W、\S。
  • 量词：*（0+）、+（1+）、?（0/1）、{n}（恰好 n 次）、{n,m}（n 到 m 次）、{n,}（至少 n 次）。
  • 锚点：^（开头）、$（结尾）、\b（单词边界）、\B（非单词边界）。
  • 分组：(...)（捕获组）、(?:...)（非捕获组）、(? ...)（命名捕获组）。
  • 选择：|（或）——如 cat|dog 匹配 cat 或 dog。优先级最低，需要时用括号分组。
  • 字符集：[abc]（a 或 b 或 c）、[a-z]（范围）、[^abc]（排除）。

注意事项

语法注意

  • 转义字符：在正则中匹配特殊字符（.、*、+、?、(、) 等）需要用反斜杠转义——\. 匹配实际的点号。
  • 双重转义：在 JavaScript 字符串中写正则需要双重转义——\d 写成 \\d。建议使用正则字面量 /pattern/。
  • 捕获组编号：捕获组按左括号顺序编号——$1 是第一个 (，$2 是第二个。嵌套括号按左括号出现顺序编号。

标志说明

  • g（全局）：匹配所有结果——不勾选时只返回第一个匹配。
  • i（忽略大小写）：匹配时不区分大小写——abc 也能匹配 ABC。
  • m（多行）：^ 和 $ 匹配每行的开头和结尾——而不只是整个字符串的开头和结尾。
  • s（点号匹配全部）：. 也匹配换行符——默认情况下 . 不匹配 \n。
  • u（Unicode）：启用 Unicode 模式——正确处理 emoji 和其他 Unicode 字符。

性能注意

  • 回溯陷阱：某些正则可能导致指数级回溯——如 (a+)+b 匹配 aaaaaaaaaac 时。避免嵌套量词。
  • 贪婪 vs 惰性：默认量词是贪婪的（匹配尽可能多）——加 ? 变为惰性（匹配尽可能少）。如 .*? 匹配到第一个可能位置就停止。
  • 大文本性能：对超大文本（>1MB）使用复杂正则时，匹配可能变慢——建议分段处理或简化正则。

安全注意

  • 纯前端处理：所有正则匹配在浏览器中完成——测试文本不上传。
  • 公共设备：如果在公共设备上测试包含敏感信息的文本，使用完毕后请清空输入。

常见问题

  • Q: 正则语法因语言而异？A: 基础语法（.、*、+、[]、()）通用。高级特性（前后瞻、命名捕获组、Unicode 属性）因语言而异——本工具支持 JS 和 Python 语法。
  • Q: 正则正确但没有匹配？A: 检查是否勾选了 g 标志（全局匹配）。不勾选时只返回第一个匹配。也检查大小写是否需要 i 标志。
  • Q: 匹配结果不完整？A: 可能是贪婪/惰性量词的问题——.* 会匹配到最后一个可能位置，.*? 匹配到第一个。根据需求选择。
  • Q: 替换结果不对？A: 检查反向引用编号——$1 对应第一个捕获组。如果用了命名捕获组，可以用 $ 引用。
