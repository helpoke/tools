Pug 格式化：模板引擎代码的整理利器

一、Pug 模板引擎简介

  • Pug（原名 Jade）是一种简洁的 HTML 模板引擎——用缩进代替尖括号，用极简语法生成完整 HTML。一行 pug 代码 div.container 等价于 <div class=\"container\"></div>。但简洁的代价是缩进必须严格正确——一个空格错位就可能导致整个模板结构错误。
  • 本工具支持 Pug 代码的格式化、验证和压缩。格式化自动修正缩进层级，验证检查语法错误并精确定位行号，压缩去除多余空行和注释生成紧凑代码。
  • 还支持 Pug 到 HTML 的实时编译——在输入框中编写 Pug 代码，输出框立即显示对应的 HTML。支持 Pug 的变量、条件、循环、混入等高级语法。

二、Pug 语法特点

  • Pug 语法：标签名直接写（不需要尖括号），class 用 . 前缀（.container），id 用 # 前缀（#main），属性用括号（(href='/')）。缩进表示嵌套关系——严格使用空格（不能用 Tab）。
  • HTML 输出：Pug 编译后生成标准 HTML——每个缩进层级对应一对嵌套标签。Pug 的一行可能对应 HTML 的多行—— Pug 的简洁性体现在用缩进替代了大量重复的标签符号。

三、核心功能

  • 格式化与验证：一键格式化 Pug 代码——自动修正缩进、对齐属性。验证模式检查语法错误并显示错误行号和列号。
  • 编译预览：Pug 代码实时编译为 HTML——方便对照查看 Pug 语法对应的 HTML 输出。
  • 压缩输出：去除空行和注释，生成紧凑的 Pug 代码——适合生产环境部署。
  • 纯前端处理：所有处理在浏览器中完成——模板代码不上传到服务器。

五、Pug 语法详解

  • 标签：直接写标签名——div、p、span、a。不写标签名默认生成 div。
  • 类和 ID：.className 表示 class 属性，#idName 表示 id 属性。可组合使用——div.container#main。
  • 属性：用圆括号包裹——a(href='/home', target='_blank')。属性之间用逗号分隔。
  • 文本内容：标签后加空格和文本——p Hello World。支持管道符 | 用于多行文本。
  • 变量插值：#{variable} 在文本中插入变量值，#{expression} 支持 JavaScript 表达式。
  • 注释：// 单行注释（不输出到 HTML），//- 静默注释（编译时完全忽略）。
  • 条件语句：if/else if/else——Pug 的条件渲染。如 if user 检查变量是否存在。
  • 循环：each item in items——遍历数组生成重复结构。支持 index 变量获取索引。

六、注意事项

  • 缩进规则：Pug 严格使用空格缩进（不能用 Tab）——同一层级的缩进空格数必须一致（通常 2 个或 4 个）。
  • 换行敏感：Pug 是换行敏感的语言——每行一个标签或指令。多行文本需要特殊语法（管道符或点号）。
  • 混合内容：标签内同时包含文本和子标签时，需要用管道符 | 标记纯文本行。

注意事项

格式注意

  • 缩进一致性：格式化会统一缩进风格——如果你的原始代码混用 Tab 和空格，格式化后全部转为空格。
  • 属性顺序：格式化不会改变属性的书写顺序——保持你原有的属性排列。
  • 注释保留：格式化保留所有注释——包括 // 和 //- 两种注释类型。
  • Include/Extend：Pug 的 include 和 extend 指令在格式化时保留路径——但工具不会解析被引用的文件。

错误处理

  • 缩进错误：最常见的 Pug 错误——缩进不一致会导致"unexpected indent"错误。格式化工具自动修复。
  • 语法错误：验证模式会报告错误类型和位置——如"unexpected token"、"missing closing bracket"。
  • 变量未定义：Pug 模板中引用未定义的变量会在编译时报错——工具会显示错误位置。
  • 混用 Tab：如果输入包含 Tab 字符，工具自动转换为空格（默认 2 空格）。

性能说明

  • 大文件：超过 500 行的 Pug 文件格式化可能较慢——建议按模块拆分。
  • 实时编译：Pug 到 HTML 的编译是实时的——输入时立即更新输出。复杂模板可能有短暂延迟。

数据安全

  • 纯前端处理：所有 Pug 代码的处理在浏览器中完成——模板不上传到服务器。
  • 代码保护：你的 Pug 模板（可能包含业务逻辑和数据结构）始终留在本地。

常见问题

  • Q: 支持 Pug 3.0 语法吗？A: 支持——包括模板继承、混入、条件、循环等全部 Pug 3.0 语法。
  • Q: 格式化后代码行为变了？A: 格式化只调整缩进和空白——不改变语义。如果行为变化，原始代码可能有缩进错误。
  • Q: 能处理 .jade 文件吗？A: Pug 就是 Jade 的改名——工具完全兼容旧版 .jade 语法。
