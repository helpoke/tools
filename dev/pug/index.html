使用说明

一、格式化功能

  • 格式化：将压缩或杂乱的Pug代码转换为结构清晰、缩进正确的格式，便于阅读和维护。
  • 校验语法：检查Pug代码的语法正确性，精确指出错误行号和上下文。
  • 压缩：将格式化的Pug代码压缩为紧凑格式，去除空白字符，减小文件体积。
  • 复制结果：一键复制格式化或压缩后的代码到剪贴板。
  • 示例数据：点击"示例数据"按钮可以查看格式化效果的示例代码。
  • 清空：快速清除所有输入和输出内容。

二、Pug 语法基础

  • 标签：Pug使用缩进表示层级，标签名后跟内容，如 div Hello。
  • 类和ID：使用 . 表示类，# 表示ID，如 div.container#main。
  • 属性：使用括号包裹属性，如 a(href="#") Link。
  • 文本：使用竖线 | 或缩进后跟文本。
  • 变量：使用 = 插入变量，如 p= title。
  • 注释：使用 // 单行注释，//- 不输出注释。
  • 条件：使用 if、else、else if。
  • 循环：使用 each 遍历数组或对象。

三、快捷操作

  • 输入和输出区域都支持独立复制操作。
  • 状态栏会实时显示当前Pug的解析状态。
  • 错误面板会显示语法错误的详细信息和行号。
注意事项

一、格式规范

  • Pug对缩进非常敏感，必须使用空格，不能使用Tab。
  • 同级元素的缩进必须一致。
  • 属性值必须用引号包裹。
  • 标签名和属性之间需要有空格。

二、常见错误

  • 缩进错误：混用空格和Tab，或缩进不一致。
  • 语法错误：标签名拼写错误、属性格式错误等。
  • 变量未定义：使用了未定义的变量会导致编译错误。
  • 闭合错误：某些标签需要正确闭合。

三、性能提示

  • 处理超大Pug文件（超过1MB）时可能会导致浏览器卡顿。
  • 建议将大型Pug文件分段处理。

四、数据安全

  • 所有处理均在本地浏览器完成，数据不会上传到服务器。
  • 建议不要在公共设备上处理包含敏感信息的Pug代码。

五、常见问题

  • 格式化失败：检查Pug语法是否正确，特别是缩进和标签格式。
  • 校验报错：根据错误提示定位问题行，修正语法错误。
  • 复制失败：检查浏览器是否允许剪贴板访问。
