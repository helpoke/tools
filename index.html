❓常见问题 FAQ

为什么说数据是本地处理的？是如何实现的？

▼
Helpoke 使用现代浏览器的 Web API（如 FileReader、Canvas、WebAssembly 等）在客户端实现文件处理。当您上传文件时，文件仅存在于浏览器的内存中，JavaScript 代码直接读取并处理这些数据，处理完成后生成结果文件供您下载。整个过程数据从未离开您的设备，服务器只是提供网页代码，不参与数据处理。

哪些浏览器可以使用这些工具？

▼
我们的工具支持所有现代浏览器，包括 Chrome、Firefox、Safari、Edge 等最新版本。为了获得最佳体验，建议使用 Chrome 或 Firefox 浏览器。部分工具使用了较新的 Web 技术（如 WebCodecs、WebAssembly），建议保持浏览器版本为最新。

处理大文件时浏览器崩溃怎么办？

▼
由于所有处理都在浏览器内存中进行，处理超大文件（如高清视频、大量图片）时可能会占用较多内存。建议：1) 关闭其他占用内存的网页和程序；2) 分批处理文件；3) 使用 64 位浏览器；4) 确保电脑有足够的可用内存。如果仍然崩溃，可以尝试使用桌面版工具。

视频处理工具支持哪些格式？

▼
视频工具基于 FFmpeg（通过 WebAssembly 运行在浏览器中），支持主流格式包括：MP4、WebM、MOV、AVI、MKV、GIF 等。输出格式支持 MP4、WebM、GIF。由于浏览器安全限制，部分加密或特殊编码的视频可能无法处理。

为什么有些工具在离线状态下无法使用？

▼
大部分工具在首次加载后可以离线使用，但以下情况需要网络：1) 首次访问某工具时需要加载网页代码；2) 部分工具依赖外部库（如 FFmpeg、Mermaid），首次使用时需要下载；3) 使用 CDN 加速的资源需要网络。建议在网络良好时预先访问需要使用的工具，之后即可离线使用。
