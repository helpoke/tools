什么是Markdown编辑器？

Markdown编辑器是一款免费的在线文档写作工具，专为需要快速编写格式化文档的用户设计。Markdown 是一种轻量级标记语言，通过简单的符号（如 #、*、- 等）即可实现标题、加粗、列表、表格等排版效果，被广泛应用于技术文档、博客写作、README 文件编写等场景。本工具提供了所见即所得的写作环境，左侧编辑、右侧实时渲染，让您专注于内容创作而无需担心语法细节。

传统的 Markdown 写作往往需要在编辑器和预览工具之间来回切换，或者安装 Typora、VS Code 等本地软件。本工具完全运行在浏览器中，打开网页即可使用，内置语法快捷工具栏，即使不熟悉 Markdown 语法的新手也能快速上手。写作完成后，您可以一键下载 Markdown 源文件，或导出为带样式的 HTML 文件直接发布到网站，也可以复制 HTML 源码粘贴到博客后台，满足多样化的输出需求。

如何使用？

第一步：输入或导入内容

在编辑区直接输入 Markdown 文本，或点击"打开文件"按钮导入本地的 .md / .markdown / .txt 文件继续编辑。首次打开工具时会自动加载一份示例文档，帮助您快速了解支持的语法效果。

第二步：使用工具栏排版

选中需要排版的文字，点击工具栏上的对应按钮即可快速应用格式。工具栏支持标题（H1-H3）、加粗、斜体、删除线、高亮、引用、行内代码、代码块、无序列表、有序列表、任务列表、链接、图片、表格、分割线、行内公式、块级公式等语法。例如选中一段文字后点击加粗按钮，文字两侧会自动添加 ** 标记。

第三步：切换视图模式

工具栏右侧提供三种视图模式：仅编辑模式适合专注写作；编辑+预览模式（默认）左侧输入、右侧实时渲染；仅预览模式用于全屏查看最终排版效果。视图偏好会自动记住，下次打开时保持上次的选择。

第四步：导出结果

写作完成后，点击"下载 Markdown"保存 .md 源文件；点击"下载 HTML"获取带完整样式的 HTML 文件，双击即可在浏览器中查看排版效果；点击"下载 PDF"可将渲染结果按 A4 版面自动分页导出为 PDF 文档，适合打印与归档；点击"复制 HTML"可将渲染后的 HTML 源码复制到剪贴板，直接粘贴到博客或 CMS 系统中使用。

实战案例：撰写技术博客文章

假设您需要撰写一篇技术博客。打开本工具后，先用工具栏快速搭建文章结构：H1 作为文章标题，H2 划分章节；正文中使用行内代码标记技术术语，使用代码块展示示例代码，使用表格对比不同方案；写作过程中通过右侧预览实时检查排版效果；完成后点击"复制 HTML"，将源码粘贴到博客后台的 HTML 编辑器中直接发布，或下载 HTML 文件存档。整个过程中编辑内容自动保存在浏览器本地，即使意外刷新页面也不会丢失稿件。

常见问题与解答

问：编辑内容会自动保存吗？

答：会。每次输入停止后，工具会自动将内容保存到浏览器本地存储（localStorage），刷新页面或下次访问时会自动恢复。但请注意，自动保存仅保存在当前浏览器中，清除浏览器缓存或更换设备后无法恢复，重要文档请务必下载备份。

问：支持哪些 Markdown 语法？

答：支持标准 Markdown 常用语法与常用扩展语法，包括六级标题（含 Setext 写法）、加粗、斜体、删除线、高亮、上下标、行内代码、代码块、嵌套引用、有序/无序/任务列表（支持多层嵌套）、链接、图片、自动链接、表格、分割线和脚注，以及数学公式（$...$ 行内公式、$$...$$ 块级公式，KaTeX 渲染，如 $E=mc^2$）。复杂嵌套结构的渲染效果可能与 GitHub 等平台略有差异。

问：如何导出 PDF 文件？

答：点击"下载 PDF"按钮，工具会将预览区的渲染结果按 A4 版面自动分页生成 PDF 文档。导出生成过程完全在本地浏览器中完成，文档内容不会上传到任何服务器。若文档较长，生成可能需要几秒钟，期间请耐心等待按钮恢复。

问：下载的 HTML 文件可以直接发布吗？

答：可以。下载的 HTML 文件内嵌了完整的排版样式（包括标题、代码块、表格等），无需任何外部资源即可在浏览器中正常显示，可直接用于静态网站发布或邮件发送。如需嵌入现有网站，建议使用"复制 HTML"功能仅复制正文部分的 HTML 代码。

问：为什么预览中的图片无法显示？

答：文档中的图片通过网络地址引用，请确认图片地址正确且可公开访问。部分网站对图片设置了防盗链限制，这类图片无法在第三方页面中显示。此外，出于安全考虑，工具会过滤 javascript: 等危险协议的链接地址。

问：清空内容后还能找回吗？

答：清空操作会同时清除浏览器中自动保存的内容，无法找回。因此清空前工具会弹出确认提示，请务必确认内容已备份。日常使用中建议养成及时下载 .md 源文件的习惯。
