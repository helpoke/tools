Markdown 编辑器：实时预览的专业写作工具

一、为什么选择 Markdown 写作

  • Word 的格式工具栏分散注意力——写文章时不断用鼠标选择字体、字号、颜色，打断了写作思路。Markdown 用简洁的语法标记格式——**加粗**、*斜体*、# 标题——双手不需要离开键盘，专注于内容本身而非排版。
  • 本工具提供完整的 Markdown 编辑环境——左侧编辑器实时预览右侧渲染效果。支持三种视图模式：纯编辑、分屏（左编辑右预览）、纯预览。工具栏提供常用格式按钮——标题、加粗、斜体、引用、代码块、表格、链接、图片等。
  • 支持数学公式（KaTeX）、任务列表、删除线、高亮等扩展语法。导出支持 Markdown 源文件、HTML 文件和 PDF 文件三种格式。自动保存功能确保内容不会丢失——刷新页面后自动恢复上次编辑的内容。

二、核心功能

  • 实时编辑：左侧编辑器输入 Markdown 语法，右侧立即显示渲染效果——所见即所得的写作体验。
  • 三种视图：纯编辑模式（全屏编辑）、分屏模式（左编辑右预览）、纯预览模式（全屏预览）——一键切换。
  • 文件操作：打开本地 .md 文件编辑，导出为 .md（源文件）、.html（网页）或 .pdf（文档）格式。
  • 自动保存：编辑内容自动保存到浏览器本地存储——刷新页面或意外关闭后自动恢复。
  • 纯前端处理：所有编辑和导出在浏览器中完成——文档内容不上传到服务器。

Markdown 编辑指南

编辑操作

  • 直接输入：在编辑器中直接输入 Markdown 文本——支持所有标准 Markdown 语法。
  • 工具栏：使用工具栏按钮快速插入格式——标题、加粗、斜体、引用、代码、表格等。
  • 快捷键：Ctrl+B 加粗、Ctrl+I 斜体、Ctrl+K 链接——常用格式一键插入。

视图切换

  • 编辑模式：全屏编辑器——适合专注写作，不需要看渲染效果时。
  • 分屏模式：左编辑右预览——最常用的模式，实时看到写作效果。
  • 预览模式：全屏预览——适合最终审阅和展示。

导出操作

  • 导出 Markdown：保存为 .md 文件——保留所有 Markdown 语法标记。
  • 导出 HTML：保存为 .html 文件——可直接在浏览器中打开查看。
  • 导出 PDF：保存为 .pdf 文件——适合打印和分享。支持数学公式渲染。
  • 复制 HTML：一键复制渲染后的 HTML 代码——粘贴到博客平台或 CMS 系统。

注意事项

数据安全

  • 纯前端处理：所有编辑和导出在浏览器中完成——文档内容不上传到服务器。
  • 本地存储：自动保存使用浏览器 localStorage——清除浏览器数据会丢失自动保存的内容。

语法说明

  • 标准语法：支持 CommonMark 标准——标题、段落、列表、引用、代码块、链接、图片、分隔线。
  • 扩展语法：支持 GFM（GitHub Flavored Markdown）扩展——表格、任务列表、删除线、自动链接。

文件说明

  • 打开文件：支持打开 .md 和 .txt 文件——文件内容加载到编辑器中。
  • 编码格式：文件读写使用 UTF-8 编码——确保中文等多字节字符正确显示。

常见问题

  • Q: 数学公式不显示？A: 使用 $...$ 包裹行内公式，$$...$$ 包裹块级公式——确保 KaTeX 库正确加载。
  • Q: 自动保存的内容在哪？A: 存储在浏览器 localStorage 中——同一浏览器同一设备自动恢复。换浏览器或设备无法恢复。
  • Q: PDF 导出样式能自定义吗？A: PDF 导出使用默认排版样式——暂不支持自定义 CSS。如需自定义样式，先导出 HTML 再自行调整。
