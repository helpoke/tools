工具介绍

一、解决的问题

  • 无需安装任何软件，打开浏览器即可编写和预览 Markdown 文档。
  • 写作时实时查看渲染效果，避免语法错误导致的排版问题。
  • 一键导出 Markdown 源文件、渲染后的 HTML 文件或 PDF 文档，方便分享与发布。

二、核心功能

  • 快捷编辑：工具栏一键插入标题、加粗、斜体、列表、表格等常用语法。
  • 实时预览：编辑内容即时渲染，支持仅编辑、编辑+预览、仅预览三种视图。
  • 文件管理：支持打开本地 Markdown 文件继续编辑，完成后可下载 .md、.html 或 .pdf 文件。
  • 自动保存：编辑内容自动保存在浏览器本地，刷新页面不丢失。
  • 数据安全：所有数据仅在本地处理，不会上传到服务器。

使用说明

一、编辑内容

  • 直接输入：在左侧编辑区直接输入 Markdown 语法文本。
  • 工具栏辅助：选中文字后点击工具栏按钮，可快速应用加粗、斜体、标题等格式。
  • 打开文件：点击"打开文件"按钮可导入本地 .md / .markdown / .txt 文件继续编辑。

二、切换视图

  • 仅编辑：专注写作，隐藏预览区域。
  • 编辑+预览：左侧编辑、右侧实时预览，默认模式。
  • 仅预览：全屏查看最终渲染效果。

三、导出结果

  • 下载 Markdown：将当前编辑内容保存为 .md 文件。
  • 下载 HTML：将渲染结果保存为带样式的完整 HTML 文件，可直接在浏览器打开。
  • 下载 PDF：将渲染结果按 A4 版面自动分页导出为 PDF 文档，适合打印与归档。
  • 复制 HTML：一键复制渲染后的 HTML 源码，便于粘贴到博客或 CMS 系统。

注意事项

一、数据安全

  • 所有编辑和渲染均在本地浏览器中完成，内容不会上传到服务器。
  • 自动保存的数据存储在浏览器本地存储中，清除浏览器缓存可能导致内容丢失。

二、语法支持

  • 支持标题（Setext/ATX）、加粗、斜体、删除线、高亮、上下标、引用、代码、有序/无序/任务列表（支持嵌套）、链接、图片、自动链接、表格、分割线、脚注等语法。
  • 复杂嵌套结构的渲染效果可能与部分平台略有差异，建议导出前先在预览区确认。

三、文件相关

  • 打开文件仅支持 .md / .markdown / .txt 文本格式。
  • 请及时下载保存重要文档，避免浏览器缓存清理导致内容丢失。

四、常见问题

  • 预览不更新：预览为实时渲染，如遇异常可切换视图模式刷新。
  • 下载失败：检查浏览器下载权限，或尝试使用其他现代浏览器。
  • 内容丢失：编辑内容会自动保存到浏览器本地，清除站点数据前请先下载备份。
