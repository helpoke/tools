使用说明

一、格式化功能

  • 格式化：将压缩的JSON字符串转换为带缩进的易读格式，支持多级缩进和语法高亮显示，便于阅读和调试。
  • 压缩：将格式化的JSON压缩为一行，并保持转义字符，适用于传输和存储场景。
  • 转义/去转义：将JSON中的特殊字符（如引号、换行符等）进行转义/去转义处理，适用于需要在代码中嵌入JSON字符串的场景。
  • 折叠：对于复杂的嵌套JSON结构，可以一键折叠所有节点，方便快速概览整体结构。
  • 换行：将一行压缩的JSON字符串按结构自动换行，便于查看长字符串内容。

二、比对功能

  • 差异高亮：同时输入两段JSON数据，系统会逐行对比并高亮显示所有差异点，支持新增、删除、修改三种差异类型。
  • 同步操作：支持同步格式化、同步压缩、同步转义和同步清除两个编辑框的内容，提高比对效率。
  • 节点标记：对于数组和对象，会标记出具体是哪个元素或属性发生了变化。

三、JSON转Java Bean

  • 自动转换：根据JSON结构自动生成对应的Java实体类代码，包括字段名、类型、getter/setter方法。
  • 类型推断：自动识别JSON中的数据类型（字符串、数字、布尔值、数组、对象等）并映射为Java类型。
  • 值自动填充：转换时会保留JSON中的实际值作为示例，便于理解和测试。
  • Java Bean转JSON：支持反向转换，将Java Bean代码转换回JSON格式。

四、JSON与XML互转

  • JSON转XML：将JSON数据结构转换为标准的XML格式，支持嵌套结构和数组的正确转换。
  • XML转JSON：将XML文档转换为JSON格式，保留元素名称、属性和文本内容。
  • 格式优化：转换后的XML会自动格式化，便于阅读和编辑。

注意事项

一、数据安全

  • 所有处理均在本地浏览器中完成，数据不会上传到服务器，也不会被记录或存储。
  • 建议不要在公共设备上处理包含敏感信息的JSON数据。
  • 处理完成后建议清空编辑框内容，避免敏感信息残留。

二、格式要求

  • 输入的JSON数据必须符合标准JSON语法规范，否则会提示语法错误。
  • JSON中的字符串必须使用双引号包裹，不能使用单引号。
  • 对象的最后一个属性和数组的最后一个元素后面不能有逗号。
  • 支持的JSON值类型包括：字符串、数字、布尔值、null、数组、对象。

三、性能提示

  • 处理超大JSON数据（超过10MB）时可能会导致浏览器卡顿或响应变慢。
  • 对于特别复杂的嵌套结构，折叠和展开操作可能会有延迟。
  • 建议将大型JSON文件分段处理，避免一次性加载过多数据。

四、浏览器兼容性

  • 建议使用现代浏览器（Chrome 80+、Firefox 75+、Edge 80+、Safari 13+）以获得最佳体验。
  • 旧版浏览器可能不支持某些高级功能，如语法高亮和节点折叠。
  • 移动端浏览器支持有限，建议在桌面端使用以获得更好的编辑体验。

五、编码问题

  • 确保输入数据使用UTF-8编码，避免中文和其他非ASCII字符出现乱码。
  • 如果从其他文件复制JSON数据，注意检查是否包含不可见字符或BOM头。
  • 转义功能会自动处理中文和特殊字符，确保转换后的JSON可以正确解析。

六、常见问题

  • 格式化报错：请检查JSON语法是否正确，特别是括号是否匹配、逗号位置是否正确。
  • 比对结果不准确：确保两段JSON的结构相似，建议先分别格式化后再进行比对。
  • 转换结果不符合预期：复杂的嵌套结构可能需要手动调整，建议检查生成的代码是否符合业务需求。
