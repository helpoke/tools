一、TOP 高频必做（使用率最高，优先开发）

	JSON 格式化 / 压缩 / 校验 / 转义
	时间戳 ↔ 北京时间 转换
	Base64 编解码（文本 + 文件）
	URL 编码 / 解码
	MD5/SHA256/SHA512 哈希加密
	二维码生成 & 二维码解析
	进制转换 2/8/10/16 互转
	RGB/HEX/HSL 颜色互转 + 取色器
	随机密码生成器
	Unicode 中文互转

二、第二梯队（日常开发高频，次优先）

	HTML 格式化 / 压缩
	CSS/JS 格式化 / 压缩
	SQL 格式化 / 美化
	正则表达式在线测试
	JSON ↔ CSV 互转
	XML 格式化 / 压缩 / JSON 互转
	文本对比 Diff 工具
	简繁体中文转换
	汉字转拼音
	单位换算（长度 / 重量 / 面积 / 温度）

三、第三梯队（程序员常用，中小流量）

	AES/DES 前后端加解密
	RSA 密钥生成 / 加密解密
	HMAC 签名生成
	Markdown 在线编辑器 转 HTML
	Mermaid 流程图 / 架构图生成
	图片压缩（前端无损压缩）
	图片旋转 / 裁剪 / 尺寸修改
	ASCII 字符画生成
	HTML 实体编解码
	IP 地址归属地查询（前端接口即可）
	
	
四、第四梯队（小众但粘性高）

	随机昵称 / 随机名字生成
	文本去重 / 行数统计 / 排序
	大小写批量转换、空格清理
	Cron 表达式在线校验生成
	JWT 在线解析 / 调试
	Cookie/Header 编解码
	CSS 渐变生成器
	图片 Base64 互转
	条形码生成（CODE128/EAN）
	时区时间转换
	
	
五、第五梯队（娱乐 / 副业向，后期补）

	表情包文字生成
	随机抽签 / 摇号工具
	倒计时生成器
	摩斯密码编解码
	生日星座测算
